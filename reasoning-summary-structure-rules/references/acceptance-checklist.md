# 总结发送前自检与通过驳回标准（强制）

- `SUMMARY-GATE-PMW-001` 是总结闸门硬失败条件：存在任何未决 `request_user_input` / `WAITING_DECISION`，包括空答案、缺失答案或宿主隐式超时未解决时，不得输出冻结集合内的任何可见内容（`commentary`、`limited_plan`、`pending_summary`、`proposed_plan`、`final`、`summary`、`final_answer`、`task_complete`、`result_and_conclusion`）或“结果与结论”；必须回到同一选择框重发循环。
- 收口前任务状态检查是硬条件：输出最终总结前必须核对宿主任务列表（宿主提供时）；存在 pending / in_progress 任务却既未继续执行也未输出显式中断点就输出“已完成”式总结时，禁止发送。
- 通过：必填与条件触发项满足要求、顺序正确、内容可复核；收口前任务状态检查已执行——存在未完成必需项时已继续执行或输出显式中断点，任务全部完成才使用“已完成”式收口；且解释性自然语言保持简体中文；T2 已完成图形适用性判断，适用时先图后文且每张图具备图形目的、关联 ID 与图文一致性，不适用时处理符合条件规则；T0/T1 已按档位省略图形化总览；无真实阻断且台账为空时改动点位于总结最后，台账非空时知识引用位于总结最后且改动点紧邻其前，引用行均可回指真实的文件读/写调用；标题层级与字号符合视觉规范；一句话结论已承载结果、关键数字/文件与验证状态；结果区（T2）或「方案与结果」（T1）只承载结论行未覆盖的增量信息，具体可复核且不与结论行重复；同一事实未跨小节复述（「知识引用」登记行与异步任务标识字段除外）；无 ⚠️ 偏差时未输出三行对照表；启动了后台异步任务时「🔄 后台异步任务」分流小节位于「结果与结论」之后，任务标识、轮询节奏、结果回流渠道、用户等待语义与宿主任务列表映射齐全，异步任务已通过 `TaskCreate` 在宿主任务列表登记（描述三段式：做什么 + 任务标识 + 何时查看）且条目可回指任务标识，并未误报为阻断或后续；真实 `blocked/manual_handoff` 时引用共享契约完整渲染状态、阶段、依据与证据、已尝试与停止条件、影响、1-3 条解决计划和恢复验证 / 重入点，并将该区块置于最后；若不存在原执行计划内未完成必需项、真实阻断，且用户未明确要求后续建议，可直接以结果结论收口，不追加“下一步状态 / 下一步建议 / 等待用户新指令 / 无需继续动作”等任何后续占位；简单单点任务已使用最小总结模板：T0 已使用 T0 极简模板，T1 主节 ≤ 4 个且无被省略小节残留。
- 驳回：缺任一必填项，或条件项应出现却未出现，或结构顺序明显错乱；或总结、结论、中断点或阶段收口中列出了需用户裁定/决策的事项，却未给出 Agent 明确推荐建议（加粗倾向与理由）、清晰的可选方案选项（选项 A/B）或未声明若未做裁定默认推进的最安全兜底方案，把决策思考成本或推进死锁风险推给用户；或引用台账非空却缺少「知识引用」小节、台账为空却输出该小节或空表、引用行无法回指本轮真实的文件读/写调用、引用小节未置于末尾、把笔记正文或片段摘录写进引用表、或在其它小节重复同一知识库事实；或一句话结论只有“已完成”等状态词、未承载结果+关键数字/文件+验证状态，或结果区超过 3 句、为凑数添加空泛句子，或复制命令、完整测试清单、逐文件改动和执行流水账；或同一事实在多个小节重复出现（「知识引用」登记行与异步任务标识字段除外）；或无 ⚠️ 偏差却输出三行一致性对照表、或存在偏差却未输出偏差行；或 T1 主节超过 4 个、T0 输出了应省略的小节；或结论与结果区堆砌空泛形容而无具体数字或对象；或存在明显流程、依赖、状态、交互、执行链或量化结果却未做图形适用性判断；或图形位于长段文字之后、缺图形目的/关联 ID、图文术语漂移、节点连线不完整、虚构事实数据、使用无意义占位图，或简单任务为了形式强制造图；或违反「图形可读性约束（强制）」任何一条——默认用了 `flowchart TD` 而非 `LR`、单图节点 > 8 个、节点文字 > 8 个汉字 / 5 个英文单词、未加 `%%{init:...}%%` 基础字号与间距配置、主流程 > 5 节点未用 `subgraph` 分组；或无真实阻断时改动点未放在最后；或启动了后台异步任务却未输出「🔄 后台异步任务」分流小节、小节位置不在「结果与结论」之后、缺少任务标识/轮询节奏/结果回流渠道/用户等待语义/宿主任务列表映射任一字段，或启动异步任务但未在宿主任务列表登记（`TaskCreate`）、条目描述缺“做什么 + 任务标识 + 何时查看”三段式、条目无法回指任务标识，或把异步等待写成“任务未完成 / 阻断 / 后续内容”等误导用户的状态；或真实阻断时未将“任务阻断收口”置于最后、缺少共享契约字段、渲染了多套解决计划，或把 `limited/not_applicable` 误报为任务阻断；或标题未用 markdown 标题语法、字号层级不分；或把普通说明、方案、流程、总结、审查报告、线程拆分或状态回报包进 ` ```text ` / 无语言代码围栏 / 缩进代码块 / HTML；或仍单列“函数注释核对”节点；或结果与结论未明确回写本次解决的问题 / 诉求与确认状态；或不存在三类合法后续（原执行计划内未完成必需项 / 阻断项 / 用户显式要求的建议）却仍强行追加新的执行建议、下一步区块、等待指令文案、无需继续动作或其他扩散性后续；或当前运行环境仍有显式状态未收口却只写完成文案、没有真实状态收口动作；或宿主任务列表存在 pending / in_progress 任务，却既未继续执行也未输出显式中断点就输出“已完成”式总结；或已声明命中本 skill 却在发出前跳过发送前强制自检，直接以未套用总结容器的口语化文本、普通确认句（如“已保存到...”“已完成...”）收尾；或推理过程、中间进度或最终总结出现成段非中文（英文 / 日文等）自然语言，且非代码符号、命令、路径、原始字段名、报错原文等技术片段；或改动点/正文中的项目内生成或修改文件路径只用行内代码反引号或纯文本输出而未使用可点击 Markdown 链接。
