# Imagegen 错误案例库

本文件只保存已复现、已解决并完成本地验证的生图错误，服务 `imagegen/SKILL.md` 的持续迭代；不替代当前代码、平台实时配置或用户当前指令。

> **2026-09-05 通道切换说明**：CLI 通道由 OpenAI（`image_gen.py`）切换为 AI Hive（`scripts/imagegen.py`，固定 `public_model_gpt_image_2`）。旧 OpenAI 通道案例（IMG-001~003 的尺寸/透明/参数契约）已随通道删除标记为 `superseded`，仅保留结构与可迁移的通用错误模式；AI Hive 通道真实案例待实际使用积累。

## 使用与维护规则

- 先按错误类型、模型、调用模式和根因匹配案例，再执行解决方案；不匹配不强行套用。
- 解决方案须用同一输入和同一成功标准完成本地验证后才允许写入 `candidate`；仅退出码为 0 不算验证完成。
- `active` 是唯一可在调用前自动执行的状态；`candidate` 待晋级、`conflicted` 冲突、`stale` 暂不推荐、`superseded` 已被替代、`rejected` 未通过门禁。
- `active` 晋级必须：根因确认、同输入复验、唯一 owner、脱敏、去重、可复用边界明确、至少两次独立复现或确定性代码/文档证据，且有当前任务的 skill 维护授权。
- 同一错误优先更新原案例；新方案与现有 `active` 冲突先标 `candidate`，验证获授权后再替代。
- 记录只保留最小可复现参数摘要。**禁止写入 API key、token、密码、完整 prompt、输入图片内容、完整响应体与未脱敏本机路径**；任何输出不回显凭据原值。
- 每次新增/更新补充来源与最后验证时间；无法回溯来源的不得进入 `active`。

## 案例字段

`案例 ID` / `状态` / `类型`（参数、环境、鉴权、网络/限流、模型能力、输出校验）/ `失败阶段` / `环境/版本` / `适用模型` / `错误特征` / `最小复现输入` / `根因` / `解决方案` / `验证` / `适用边界` / `授权` / `发生次数` / `首次观察` / `最后验证` / `替代关系` / `用户确认` / `来源`。写入前必须完成根因、复验、脱敏、去重、唯一 owner 检查。

## 已验证 / 可迁移案例

### IMG-004（保留，通用）：CLI 依赖缺失

- `状态`：`active` · `类型`：`环境` · `适用模型`：CLI fallback
- `错误特征`：运行时报 `requests` 导入失败或命令不存在。
- `根因`：CLI 缺运行时依赖；不是模型调用失败。
- `解决方案`：`pip3 install requests`（去底场景另需 `pip3 install pillow`）后重试；不另写一次性 wrapper，不用程序绘图冒充出图。
- `验证`：补依赖后同输入重跑通过；dry-run/最小任务返回 `taskId`。
- `来源`：AI Hive 通道脚本依赖声明；2026-09-05 通道切换后沿用。

### IMG-005（保留，通用）：CLI 无可用通道

- `状态`：`active` · `类型`：`鉴权` · `适用模型`：CLI fallback
- `错误特征`：调用提示缺少或无效 API Key（401），或找不到 `~/.ai-hive/config.json`。
- `根因`：CLI fallback 需要有效 `sk-api-*` Key；配置来源依次为 `~/.ai-hive/config.json`、`AI_HIVE_API_KEY` 环境变量、`--api-key`。
- `解决方案`：运行 `init` 引导配置或设置环境变量/传参；只提示配置位置，不回显或回写 secret；两条真实路径都不可用后明确标记尚未生成最终图片。
- `验证`：`init` 后跑最简 `generate --no-download` 返回 `taskId`。
- `来源`：AI Hive 通道鉴权逻辑；2026-09-05 通道切换后沿用。

### IMG-006（保留，通用）：限流或瞬态网络错误

- `状态`：`active` · `类型`：`网络/限流` · `适用模型`：CLI fallback
- `错误特征`：HTTP 429、rate limit、timeout、connection reset 等瞬态错误。
- `根因`：上游限流或短暂网络故障，不代表 prompt/参数/鉴权错误。
- `解决方案`：对已识别瞬态错误按退避重试（最多 3 次）；参数、鉴权与其他非瞬态错误不得自动重试；任务已提交但下载失败时用 `task --task-id` 只查原任务，不重复提交。
- `验证`：检查重试次数与退避日志；不用真实线上故障作本地验证前提。
- `来源`：AI Hive 通道任务轮询行为；2026-09-05 通道切换后沿用。

### IMG-001/002/003（superseded）：OpenAI 通道参数契约案例

- `状态`：`superseded`（OpenAI `image_gen.py` 通道已于 2026-09-05 删除）
- 历史内容：gpt-image-2 尺寸约束（16px 倍数/3840 上限/3:1/像素区间）、不支持 `background=transparent`、不支持设置 `input_fidelity`。
- **不适用于当前 AI Hive 通道**：AI Hive 的分辨率/格式/参数以平台实时 `imageConfig` 为准，禁止照抄上述约束；确需确认时用一次 `--no-download` 任务试探或查平台实时配置。

## AI Hive 通道可预期错误（待真实复现后转正式案例）

- 提示缺图片 → 该请求需参考图，补 `--image`。
- 提示模型不存在 → 平台模型下线/更名，查实时模型列表或核对 `--base-url`。
- 提示 InvalidParameter → 检查 `--param`/尺寸/数量是否符合实时 `imageConfig`。
- 任务长期 pending → 保留 `taskId` 稍后查询，不重复提交。

## 回写检查清单

1. 错误已复现且根因有代码/文档/运行证据；2. 方案已本地验证，未把静态猜测写成 `active`；3. 摘要与命令已脱敏；4. 已按 ID/特征/模型去重并更新来源与时间；5. 已记录唯一 owner、失败阶段、最小复现、边界与禁止动作；6. 状态变更与晋级有当前任务授权。
