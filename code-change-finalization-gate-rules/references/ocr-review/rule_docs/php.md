#### PHP 代码质量
- 使用已废弃的函数或特性
- 缺少类型声明（参数和返回值类型）
- 不安全的变量处理（未初始化变量的使用）

#### 安全
- SQL 注入：未使用参数化查询（PDO/prepared statements）
- XSS：输出未转义的用户输入
- 文件包含风险：`include/require` 使用了用户可控的路径
- 命令注入：使用 `exec`、`system`、`shell_exec` 等未净化输入

#### 性能
- 循环中的数据库查询（N+1 问题）
- 无缓存的重复计算

#### 最佳实践
- 使用命名空间和 PSR-4 自动加载
- 避免全局状态和单例模式的滥用
- 使用类型化参数和返回值（PHP 7+）
