#### 明显的拼写或拼写错误
- 变量名、方法名或类名声明处的拼写错误
- 日志或异常消息中包含影响可读性的拼写错误的字符串

#### 死代码
- 永远无法到达的代码块
- 声明但从未使用的变量
- 被注释掉的大块代码且无明显保留意图

#### 逻辑错误
- 错误的 if 条件或循环逻辑
- 边界条件处理错误
- 空指针解引用风险

#### 线程安全问题
- 没有同步的多线程共享状态修改
- 非原子复合操作
- 不安全的懒初始化模式

#### 性能问题
- 循环内的数据库调用
- N+1 查询问题
- 无分页的大数据集查询
- 低效算法实现

#### 安全敏感
- SQL 注入、XSS 风险
- 未经验证的用户输入
- 敏感信息暴露

#### 资源管理
- 未正确关闭的数据库连接、流、文件
- 事务未正确提交或回滚

#### 可维护性
- 硬编码的业务值
- 缺少必要的注释
- 与项目风格不一致
