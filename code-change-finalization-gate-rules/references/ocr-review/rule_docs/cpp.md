#### 明显的拼写或拼写错误
- 变量名、函数名、类名声明处的拼写错误
- 日志或异常消息中的拼写错误

#### 死代码
- 永远无法到达的代码块
- 声明但从未使用的变量
- 被注释掉的大块代码

#### 逻辑错误
- 错误的条件逻辑或循环逻辑
- 边界条件处理错误
- 空指针解引用风险

#### 内存安全
- 缓冲区溢出风险
- 使用未初始化内存
- 内存泄漏
- 悬空指针

#### 资源管理
- RAII 使用不当
- 智能指针误用
- 移动语义中的所有权问题
- 异常安全（栈展开时的资源清理）

#### 并发安全
- 数据竞争
- 死锁风险
- 原子操作使用不当

#### 模板与元编程
- 模板特化过泛导致意外匹配
- SFINAE 使用不当
- 编译期计算中的逻辑错误

#### 代码风格
- 使用 `using namespace std` 在头文件中
- 避免裸指针，优先智能指针
- 使用 `const` 和 `constexpr` 进行编译期约束
- 优先现代 C++ 特性（C++11/14/17/20）
