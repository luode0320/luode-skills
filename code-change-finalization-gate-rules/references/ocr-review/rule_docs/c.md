#### 明显的拼写或拼写错误
- 变量名、函数名、类名声明处的拼写错误
- 日志或异常消息中的拼写错误

#### 死代码
- 永远无法到达的代码块
- 声明但从未使用的变量
- 被注释掉的大块代码

#### 逻辑错误
- 错误的条件逻辑或循环逻辑
- 边界条件处理错误
- 空指针解引用风险

#### 内存安全（C 语言特有）
- 缓冲区溢出风险
- 使用未初始化内存
- 内存泄漏：分配后未释放
- 悬空指针：释放后继续使用
- 双重释放
- 字符串操作的安全隐患（strcpy、sprintf 等无边界检查的函数）

#### 安全敏感
- 格式字符串漏洞
- 整数溢出/截断
- 不安全的类型转换
- 未经验证的数组索引

#### 资源管理
- 文件句柄未关闭
- 锁未正确释放
- 动态内存管理错误

#### 可维护性
- 硬编码常量（应使用宏或枚举）
- 过度复杂的宏定义
- 缺少边界检查的缓冲区操作
