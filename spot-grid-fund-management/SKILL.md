# 现货网格资金管理模型：防守深度约束与多币沙盒制

适用于所有金融市场（加密货币、A股 ETF、美股等）的现货网格、马丁格尔与定投类量化策略。

---

## 一、核心痛点与底层逻辑

1. **主观定额的死穴（单格 30% 陷阱）**：
   若盲目将单格比例设为 30%，买入 3 次就会耗尽 90% 的可用资金。当行情仅下跌 $3 \times grid$（例如 $3 \times 8\% = 24\%$）时，账户就会彻底空仓断粮，在随后的深渊暴跌中丧失摊薄成本的能力。
2. **死板固定的天花板（资金钝化）**：
   若永远死守一个固定的绝对金额（例如 100U），当后续外部追加本金或资产规模翻倍到数万 U 时，资金利用率将被压缩到不足 5%，策略退化为巨额现金闲置。
3. **多币共享资金池的挤兑风险**：
   多币若共享流动性池，遭遇黑天鹅崩盘时，高波动币种会率先抽干所有现金，导致其他币种在暴跌时断粮。

---

## 二、防守深度联动定额模型（Depth-Anchored Grid Sizing）

### 1. 核心数学推导
开单金额绝不允许主观拍脑袋，必须由**全局目标防守深度 $D$** 与 **网格间距 $grid$** 刚性内生决定：

1. **安全开单总层数 $N$**：
   $$N = \frac{\text{目标防守深度 } D}{\text{网格间距 } grid}$$
   *(通用推荐：加密货币等高波动市场 $D \ge 80\%$；股票/ETF 市场 $D \ge 50\%$)*

2. **单格下单比例 $order\_pct$**：
   $$order\_pct = \frac{1}{N} = \frac{grid}{D}$$

3. **单格实际下单金额**：
   $$\text{单格下单金额} = order\_pct \times \text{当前实有本金} = \frac{\text{当前实有本金}}{N}$$

### 2. 标准换算速查表（以高波动市场 $D = 80\%$ 为基准）

| 网格间距 $grid$ | 目标防守深度 $D$ | 安全总层数 $N$ | 单格比例 $order\_pct$ | 特征与适用风格 |
| :---: | :---: | :---: | :---: | :--- |
| **3.0%** | 80% | **26.7 单** | **3.75%** | 超高频微震荡套利 |
| **5.0%** | 80% | **16.0 单** | **6.25%** | 高频震荡网格（回撤极低） |
| **8.0%** | 80% | **10.0 单** | **10.00%** | **标准黄金均衡配置** |
| **10.0%** | 80% | **8.0 单** | **12.50%** | 稳健中宽幅抓大反弹 |
| **15.0%** | 80% | **5.3 单** | **18.75%** | 大周期宽幅防大崩盘 |

## 三、多币控制规范：独立沙盒制（分餐制）

多币资金管理**严禁共享现金池**，必须实行物理/逻辑防火墙隔离：

1. **按配置权重切碎总资金**：
   $$\text{币种 } i \text{ 的沙盒本金} = \text{总本金} \times \text{权重}_i \quad (\sum \text{权重}_i = 100\%)$$
2. **沙盒内各自闭环运转**：
   $$\text{币种 } i \text{ 的单格金额} = \frac{\text{币种 } i \text{ 的沙盒本金}}{N_i}$$
3. **三大安全防线**：
   - **单币绝不抢钱**：单币暴跌能消耗的资金上限为其自身沙盒额度，绝不挤占其他币种储备；
   - **多币等价单币**：多币组合的整体防守深度依然严格等于 $D$；
   - **支持因地制宜**：不同波动率标的可独立配置间距与层数，互不干扰。

---

## 四、资金动态伸缩机制（入金、提现、资产翻倍）

1. **外部入金 / 资产翻倍**：
   - 当本金翻倍时，各子账户沙盒本金翻倍；
   - 单格下单金额**直接线性翻倍**，充分享受复利与规模效应；
   - **核心保障**：分母 $N$ 永久锁死，翻倍后依然保证稳稳抗下深渊暴跌，子弹永不断粮。
2. **外部提现**：
   - 本金减少，单格金额同向收敛，风险敞口自动降低。
3. **日常利润留存**：
   - 日常网格套利利润沉淀为纯现金防御池，不随每分钟市价暴躁跳变，彻底阻断牛市泡沫高位被动加杠杆的风险。

---

## 五、目标函数铁律：已平仓网格收益第一原则（2026-09-19 确认）

1. **现货无爆仓风险**：现货网格不加杠杆，永无爆仓清算风险，未平仓的浮亏本质上只是“等待下一轮上涨的现货库存”；
2. **期末总权益的随机性**：期末总权益受回测截断日当天的随机市价影响极大（若截断日恰逢回调低谷，账面市值会被人为压低），不能作为衡量策略造血能力的唯一或第一指标；
3. **回撤不是首要约束**：只要满足防守深度（保证跌 70%~80% 绝不断粮），中间的账面浮亏波动是持有现货资产的自然伴随，绝不应为了刻意追求账面低回撤而牺牲高频吐出现金流的网格套利能力；
4. **评价第一标准**：**【累计已兑现网格纯利润（Grid Profit）最大化】是策略选参的第一排序准则！** 真正落入口袋、并持续推动本金复利增长的纯现金利润，才是策略最核心的灵魂。
