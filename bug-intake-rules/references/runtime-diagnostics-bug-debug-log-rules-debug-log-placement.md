# 调试日志落点  - 优先打在分支决策点、状态变化点、上下游边界和异常抛出处。 - 一条日志至少要回答一个明确问题。 - 避免同一层同时打重复日志。 - 输出字段优先选择能区分假设的最小集合。 - **每条临时调试日志必须带唯一前缀标签**（如 `[DEBUG-a4f2]`，随机短标识），定位完成后的清理变成一次 `grep '[DEBUG-...]'` 即可回收；无标签的调试日志容易混入正式日志而存活。 - 临时调试日志也必须通过项目 `utils/log/` 封装输出，禁止 `fmt.Println`、`println`、`console.log`。 - 当前 Bug 的日志记录统一归档到项目根目录 `doc/4-bugs/` 下对应的 Bug 主文档中，命名格式参考 `artifact-storage-rules` 的时间戳模板，使用 `yyyy-MM-DD_HHmmss_问题中文简介.md`。
