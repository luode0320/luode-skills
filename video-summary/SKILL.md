# 全网视频自动化提取与深度总结 (Video Summary)

用于对各类网络视频进行自动化内容提取与结构化 AI 总结的通用技能。针对大模型无法直接在线播放流媒体链接的限制，采用**分层降本提速策略**：**优先秒级提取字幕/AI听翻字幕文本；无字幕时自动下载体积最小的 360P 标清流（或音频）进行多模态分析**，杜绝大模型“仅凭标题编造内容”的幻觉问题。

---

## 触发场景

凡用户消息中出现视频链接（或 BV 号）且伴随以下意图时自动触发：
- “总结一下这个视频 / 帮我总结”
- “提取视频字幕 / 提取笔记”
- “第一集总结 / 总结 P2 / 分析视频讲了什么”
- “提炼考点 / 整理课程大纲 / 梳理核心观点”
- 支持平台：Bilibili、YouTube、抖音、Twitter/X、Vimeo 以及各类带视频 URL 的网页。

---

## 核心工作流

### 第一步：识别链接与提取分P

1. 从用户输入中提取视频地址或 BV 号。
2. 检查用户是否指定了分集（例如“第一集”、“P3”、“第三讲”），若有，通过 `-p <序号>` 传入；若 URL 包含 `?p=X` 且用户未口头指定，默认沿用 URL 中的分P。

---

### 第二步：执行通用提取脚本（自动复用与轮转清理）

运行技能内置的多通道提取器 `video_fetcher.py`。
默认缓存路径位于系统统一用户目录 `~/.qoder/cache/video-summary`，**自带“最近 3 个历史滑动轮转清理”与“相同视频直接命中缓存”机制**：

```bash
# 默认自适应模式 (命中缓存直接返回；未命中时优先查字幕，无字幕自动下载 360P 标清流，并自动维持最近 3 个历史)
python "C:/Users/luode/.qoder/skills/video-summary/scripts/video_fetcher.py" "<视频链接>" -p <分P序号> -m auto

# 极速字幕模式 (仅查字幕，不下载任何视频，秒级返回)
python "C:/Users/luode/.qoder/skills/video-summary/scripts/video_fetcher.py" "<视频链接>" -p <分P序号> -m sub-only

# 强制标清视频模式 (适合图形推理、公式推导、PPT板书、界面实操等强依赖画面的场景)
python "C:/Users/luode/.qoder/skills/video-summary/scripts/video_fetcher.py" "<视频链接>" -p <分P序号> -m video-low
```

脚本将输出结构化 JSON 结果：
- `cached: true`：表示命中本地历史缓存，0秒极速复用已下载的内容，无需重新下载。
- `extracted_type: "subtitle"`：成功提取出字幕文本文件，带精确开始与结束时间戳。
- `extracted_type: "video_low"`：无字幕，已下载 360P/标清视频（通常仅 15~30MB）。

---

### 第三步：AI 结构化总结生成

根据第二步的产物执行对应的分析交付：

#### 1. 产物为字幕文本 (`subtitle`)
1. 使用 `Read` 工具读取脚本输出的字幕文件（`.subtitle.txt` 或 `.srt`）。
2. 根据视频主题（网课教学/数码评测/播客访谈），严格对照 [references/summary_templates.md](references/summary_templates.md) 模板输出深度分析：
   - **一句话主旨摘要**（200 字内概括要点）
   - **全局知识树 / 议题思维导图**
   - **精细化分段讲解大纲（必须附带 [mm:ss] 精确时间戳）**
   - **核心考点、公式口诀与避坑清单**（若是课程类）
   - **课后复习/行动建议**

#### 2. 产物为标清视频 (`video_low`)
1. 告知用户该视频未包含开放字幕，已准备好体积最小的标清视频（如 360P，文件位于本地缓存）。
2. 可直接将该本地视频交由具备多模态能力的大模型（如 **Gemini 3.8 Flash** Files API）进行音画协同理解，或配合本地语音识别进行文本化总结。

---

## 缓存与存储生命周期规范 (3个历史限制)

1. **自动复用原则**：如果用户短时间内对同一个视频提出不同角度的追问或二次总结，脚本会自动命中已有的本地缓存（`cached: true`），严禁重复向远程发起网络下载。
2. **严格保持最近 3 个历史**：每次下载新视频时，脚本会自动扫描缓存目录，按最后访问时间排序，自动清理最早的历史临时数据，只保留最新的 3 个视频任务，避免长期占用硬盘。
3. **低码率标清约束**：严禁下载 1080P/4K 原画，必须保持 360P/480P 标清流，兼顾视觉 OCR 与极小磁盘占用。
