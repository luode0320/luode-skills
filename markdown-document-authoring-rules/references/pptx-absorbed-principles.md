# PPTX 原则到 Markdown 的适配矩阵

## 目的

本文件只抽取 PPTX skill 中对内容表达有帮助的原则，并把它们改写为 Markdown 可执行规则。它不复制页面尺寸、字号、英寸、固定版式或 OOXML。

## 迁移矩阵

| PPTX 原则 | Markdown 适配 | 迁移状态 |
| --- | --- | --- |
| 内容决定表达方式 | 结论用短段落，比较用表格，顺序用 Mermaid，原始证据用代码块 | 迁移 |
| 信息层次 | H1/H2/H3 和结论优先的白话开场 | 迁移 |
| 留白和分组 | 段落、列表、表格和 Mermaid 之间保留可读间距 | 迁移 |
| 左对齐和语义对比 | 正文左对齐，表格列按字段类型对齐，状态使用明确词语 | 适配 |
| 图表自解释 | 图前目的、关联 ID、图例和图后边界 | 迁移 |
| 装饰克制 | 删除没有证据作用的装饰图标和重复图形 | 迁移 |
| 最终视觉验收 | 检查渲染后的标题层次、表格宽度、Mermaid 可读性和断行 | 迁移 |
| 固定页面尺寸 | Markdown 没有幻灯片画布 | 不迁移 |
| 固定字号、英寸和页面比例 | Markdown 渲染器和阅读设备不同 | 不迁移 |
| 每页必须有视觉元素 | Markdown 不要求每个小节添加图片 | 不迁移 |
| OOXML 和 PowerPoint API | Markdown 没有对应对象模型 | 不迁移 |

## 适配原则

1. 先确认读者要做的决策，再选择文本、表格或图形。
2. 先表达结构和证据，再检查视觉密度。
3. 图形必须减少解释成本，不能只增加装饰。
4. 不能用演示稿页面规则约束可滚动的 Markdown 文档。
5. 任何固定尺寸要求都必须回到具体渲染器证据，不能从 PPTX 经验直接推导。

## 通过标准

- 每条迁移原则都有 Markdown 适配方式。
- 每条不迁移原则都有原因。
- 没有业务字段、接口契约或运行时依赖。
- 图形、表格和正文术语与公共 skill 一致。
