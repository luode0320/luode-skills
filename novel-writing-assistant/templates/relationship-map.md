# 人物关系网与情感弧光模板（言情 / 关系向专用）

> 挂载于 `references/genre-deep-yanqing.md`。本模板供在 `world-bible.md` 的「人物关系网」节，以及独立关系追踪表中使用。
> 目标：把「谁和谁什么关系、情感状态何时变化、有没有未回收的情感伏笔」**写死成可机判字段**，让 C8 关系称谓冲突规则能扫描。

## 1. 人物关系网（写入 world-bible.md，C8 解析源）

格式（一字不差，解析正则依赖它）：

```
## 人物关系网
- 林月 — 顾言：前任（已分手，第2卷末）
- 林月 — 苏白：现任恋人（第4卷确定）
- 苏白 — 顾言：情敌/旧识
```

字段约定：
- 行首 `- `，两人名用 ` — `（全角破折号或 `-`/`~`）连接，冒号后用**关系标签**。
- 关系标签只能含以下「可机判关键词」之一或多个，C8 据此归类：
  - `前/旧/ex/已分手/分手后` → 归为 `ex`
  - `妻/夫/配偶/老公/太太/夫人/媳妇/夫君/爱妻/爱人/伴侣` → 归为 `spouse`
  - `恋/男友/女友/心上人/在一起` → 归为 `lover`
  - `父/母/子/女/兄/弟/姐/妹/亲属/亲戚` → 归为 `kin`
  - `陌生/素不相识/毫无关系/不相识` → 归为 `stranger`
- 若两人关系随时间变化（如 前任→陌路），**用多行分别记录不同阶段的时点**，不要在一行里堆矛盾词。

## 2. 情感弧光追踪表（独立 .md，作者自用，非 C8 强制源）

| 关系对 | 阶段 | 起始卷章 | 关键事件 | 终止卷章 | 状态 |
|---|---|---|---|---|---|
| 林月—顾言 | 暧昧 | 第1卷3章 | 雨夜初遇 | 第2卷10章 | 已结束(分手) |
| 林月—苏白 | 相知 | 第3卷1章 | 合作办案 | — | 进行中 |

- 每对关系一条主弧；支线（误会、吃醋、和解）作为事件挂到主弧下。
- 「状态」枚举：进行中 / 已结束 / 暂停 / 转折中。

## 3. 情感伏笔表（写入 plot-board.md，复用 C5 回收机制）

```
## 情感伏笔
- F7：林月童年创伤导致亲密恐惧 — 埋于：第1卷 — 状态：待回收
- F8：顾言隐瞒的家族联姻 — 埋于：第2卷 — 状态：待回收
```

- 与主线伏笔共用 `F` 编号空间，C5 统一监控「待回收」超期。

## 4. 关系一致性自查清单（写完后逐条勾）

- [ ] 每对核心人物在关系网中有且仅有「当前有效」的一行关系标签。
- [ ] 关系标签不含互斥词共存（如同一行既写「前任」又写「妻子」）。
- [ ] 情感状态变化（分手/在一起）都在时间线 `timeline.md` 有对应节点。
- [ ] 所有情感伏笔在 plot-board 有 `F` 编号与状态。
- [ ] 回忆/倒叙段落若提及旧称谓（如「我的前妻」），已在正文明确标注回忆语境，避免 C8 误报。
