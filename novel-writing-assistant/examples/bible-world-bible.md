# 世界观圣经：穰县醒（示例）

> 这是 novel-writing-assistant 的「建库 → 写 → 审计」正式示例。
> 整目录复制即可运行：`python scripts/consistency_audit.py --bible examples/sanguo-demo/bible --ms examples/sanguo-demo/manuscript`
> 期望结果：ERROR 0 / WARN 3（3 条为长线伏笔 F1/F2/F3「待回收」提醒，非逻辑错误）。

## 1. 基础设定
- 类型：历史穿越（东汉末年）
- 时代背景：东汉建安五年（公元 200 年），官渡之战前后
- 核心冲突：现代青年陈恪魂穿小吏陈默之躯，欲在乱世自保并影响时局

## 2. 世界规则（确定性校验 C4 的来源，须写「可判定形式」）
- 规则 R1：火药 仅 陈默（携现代记忆）可掌握，他人 不得 使用（建安五年尚无火药实战应用）
- 规则 R2：陈默 须于 建安五年九月前 抵达许昌并面见荀彧

## 3. 力量 / 能力体系
- 主角外挂：现代史识、农桑防疫与后勤之识，非武力；火药知识为终极底牌，绝不轻示

## 4. 地理 / 机构
- 穰县：南阳属县，故事起点
- 许昌：曹操霸府所在，荀彧留守
- 官渡：曹操与袁绍决战地

## 5. 结构规划
- 本示例仅含第一卷前 3 章作演示（完整 25 章压测见 dev 目录）
- 字数预算：演示章每章约 300–400 字
