# 一致性校验规则集（consistency-rules）

`scripts/consistency_audit.py` 的每条规则在此定义判据、级别与**已知误报边界**。规则全部确定性、可复跑，不调模型。

## 规则总表（10 类）

| 编号 | 规则 | 判据（机器可判定） | 级别 | 误报边界 |
|---|---|---|---|---|
| C1 | 名字一致性 | bible 规范人名集合 vs manuscript 中「形近/音近/同拼音」变体 | WARN | 译名/昵称/代号属正常变体，需白名单 |
| C2 | 时间线冲突 | 正文对同实体用「生命周期谓词（出生/生于/坐化/入门…）」断言的日期，与 timeline.md 该事件日期矛盾（已支持年号纪年如 天启X年、星历X年；自动剥离「生于/卒于/到了」等前导动词噪声） | WARN | 多视角叙述的时间差、倒叙不在此列；仅在断言冲突日期时报告，避免故事当下时间误报 |
| C3 | 在场性漂移 | 人物「当前状态=已故/失踪/不在场时段」却在 manuscript 正常出场 | ERROR | 明确「回忆/幻觉/复活设定」段落应排除 |
| C4 | 设定违反 | world-bible「世界规则」含「禁止/不得/不能…」条款时，manuscript 出现被禁动作（按核心动词匹配，兼容近义改写如『强行运转灵力』命中『运转灵力』） | ERROR | 规则模糊（形容词式）无法机判，须写可判定形式 |
| C5 | 伏笔未回收 | plot-board 标记「待回收」且已过预期回收卷仍未出现 | WARN | 长线伏笔允许跨多卷，按作者设定卷数判 |
| C6 | 仙侠境界倒退 | world-bible「境界序列」定义仙侠境界序，人物卡「当前境界」标注；正文出现『X 跌落至/跌回/被打落 Y』且 Y 在序列中更靠前 → ERROR | ERROR | 上下文含「散功/自废/兵解/重修/封印修为」属正常情节，已自动豁免；非仙侠项目（无境界序列）自动跳过 |
| C7 | 物证状态链 | world-bible「关键物品/设备状态」记『物品X终态=损毁/遗失』，manuscript 出现 X 恢复/运转且无修复豁免词 → WARN | WARN | 损毁前章节（如『事故前它正常运转』）属正常，需人工确认时点；上下文含「修复/重铸/复制/克隆替换」豁免不报；未登记物品状态则自动跳过 |
| C8 | 关系称谓冲突 | world-bible「人物关系网」标注 A—B 为 ex/stranger，manuscript 却以 spouse/lover/kin 类称谓同时指称两人 → WARN | WARN | 回忆/倒叙/传闻中旧称谓属正常，上下文含「回忆/想起/当年/听说」等豁免词不报；未登记该 pair 或标签无冲突类别则跳过 |
| C9 | 线索/证据状态链 | world-bible「线索/证物/证据状态」记『线索X终态=销毁/遗失/封存』，manuscript 出现 X 重现/被检验/被出示且无伪造豁免词 → WARN | WARN | 线索在更早章节已出现属正常，需人工确认时点；上下文含「伪造/调包/复制/新发现」豁免不报；未登记线索则自动跳过 |
| C10 | 游戏系统面板一致性 | world-bible「系统面板」记『角色X 等级=Lv.N / 已学技能=[...]』，manuscript 出现 X 等级跌落/退至 M 且 M<N → ERROR；X 施展未在列表的技能名 → WARN | ERROR/WARN | 等级正则要求 Lv./等级/级 上下文，避免「第3层」「50米」误报；未学技能仅对像技能名（术/法/技/咒…结尾）告警且排除「魔法/法术」泛称；自废/封印/重生/转生/试炼 豁免等级倒退；面板未登记等级/技能则跳过该项 |

## 判据细节

### C1 名字一致性
- 取 bible `characters/*.md` 的 `# 人物：<规范名>` 与「别名」字段为规范集。
- 对 manuscript 做分词/按行扫描，对每段 token 与规范名做编辑距离（≤2）或拼音相似度比对。
- 命中非规范集的近似串 → 报告「疑似名字变体：规范『X』/ 疑似『Y』@章节」。
- **白名单**：别名、昵称、代号在 bible 登记的，不报。

### C2 时间线冲突
- 解析 timeline.md 的 `T<n>：<时点> — 事件`。
- 解析 manuscript 中 `YYYY-MM-DD` / `纪元X年` / `第N天` 形式时点。
- 同一事件时点不一致 → 报告。

### C3 在场性漂移
- 解析人物卡「当前状态」与「在场时间线」。
- manuscript 中该人物在「已故/失踪/不在场」时段出场且无回忆/幻觉标记 → ERROR。

### C4 设定违反
- 解析 world-bible「世界规则 Rn」。
- 规则须为「主体+条件+结果」可判定形式；模糊规则跳过并提示「规则 Rn 不可机判，建议改写」。
- manuscript 违反明确规则 → ERROR，附证据句。

### C5 伏笔未回收
- 解析 plot-board「伏笔」的「状态」「埋于/回收卷」。
- 已超过作者设定回收卷仍未标记「已回收」→ WARN。

### C6 仙侠境界倒退
- 依赖 `genre-deep-xianxia.md` 规定的 bible 字段：`world-bible.md` 的「境界序列：A < B < C …」+ 人物卡的「当前境界」。
- 解析正文「<角色名> … 跌落至/跌回/被打落/退至/沦为 <境界词>」，若目标境界在序列中排在「当前境界」之前 → ERROR。
- 豁免词（散功/自废/兵解/重修/封印修为/境界被废）出现于上下文 → 不报，避免误伤正常情节。
- 无「境界序列」字段时（非仙侠/未填）自动跳过，不误报。

### C7 物证状态链
- 依赖 `genre-deep-kehuan.md` 规定的 bible 字段：`world-bible.md` 的「关键物品/设备状态」行，格式 `- 物品：<名> | 终态：<状态> | <损毁/遗失>于：<时点>`。
- 终态含「损毁/毁坏/报废/遗失/丢失/湮灭/摧毁/熔毁」之一即纳入监控。
- 解析正文「<物品名> … 恢复/重启/重新启动/重新运转/完好无损/再次运转/重新激活…」，若 bible 记该物品已终态负面且无豁免词（修复/重铸/复制/克隆/替换/重建）→ WARN。
- 设计为 WARN 而非 ERROR：物证状态常涉时间线，纯文本无时点会误报早期章节（损毁前正常运转属正常），由作者确认时点。
- 豁免词（修复/重铸/复制/克隆/替换/重建/复原/再造/重生/备份）出现于上下文 → 不报，避免误伤正常情节。
- 无「物品：」行时（非科幻/未填）自动跳过，不误报。

### C9 线索/证据状态链
- 依赖 `genre-deep-urban-suspense.md` 规定的 bible 字段：`world-bible.md` 的「线索/证物/证据状态」行，格式 `- 线索：<名> | 终态：<状态> | <销毁/遗失>于：<时点>`（支持线索/证物/证据三种写法）。
- 终态含「销毁/损毁/遗失/丢失/灭失/焚毁/湮灭/粉碎/没收/封存」之一即纳入监控。
- 解析正文「<线索名> … 重现/被找到/被检验/被出示/浮出水面…」，若 bible 记该线索已终态负面且无豁免词（伪造/调包/复制/仿制/新发现/备份）→ WARN。
- 设计为 WARN 而非 ERROR：线索在更早章节已出现属正常叙事，纯文本无时点会误报，由作者确认时点。
- 豁免词（伪造/调包/复制/仿制/新发现/另寻/新线索/新证据）出现于上下文 → 不报，说明是另一份或新证据。
- 无「线索/证物/证据：」行时（非悬疑/未填）自动跳过，不误报。

### C10 游戏系统面板一致性
- 依赖 `genre-deep-game.md` 规定的 bible 字段：`world-bible.md` 的「系统面板」行，格式 `- 角色：<名> | 等级：Lv.<N> | 属性：... | 已学技能：<a>, <b>`（等级解析容错 Lv.5/等级5/5级；中文数字无法解析则跳过该项）。
- **等级倒退 (ERROR)**：解析正文「<角色名> … 跌落/跌回/退至/降级至/掉到/降为/回落/退回到/贬至/掉回 … (Lv.|等级)?M级?」，若 M < 面板等级 → ERROR。等级正则要求 Lv./等级/级 上下文（「第3层」「50米深谷」不匹配），避免误报。
- **未学技能使用 (WARN)**：解析正文「<角色名> … 施展/释放/使用/施放/发动/催动 [了着过出]? <技能名>」，若技能名不在面板「已学技能」且像技能名（结尾 术/法/技/咒/击/斩/波/焰/冰/雷/箭/刃/掌/拳）且非泛称（魔法/法术/灵术…）→ WARN。
- 豁免词（自废/封印/重置/重生/转生/试炼/历练/伪装/轮回）出现于等级倒退上下文 → 不报，属正常设定。
  - 无「系统面板」行（非游戏异界/未填）自动跳过，不误报。

### C11 首版 AI 味探测（文风信号，非逻辑错误）
- 定位：首版草稿常带"机器痕迹"。C11 逐章扫描八类确定性高的机械套路，超阈值打 WARN，**供作者二遍改写参考；不是逻辑错误、不影响一致性**。
- 八类信号与默认阈值（见 `consistency_audit.py` 的 `C11_THRESHOLDS`，可据文风微调）：
  - 比喻连接词（仿佛/似乎/宛若/犹如/宛如/好像/如同…），每章 >3；
  - 破折号「——」每章 >5；
  - 套路填充词（不知何时/不知不觉/忽然/猛地/与此同时…），每章 >3；
  - 情绪直给标签（他感到/心中涌起/一种莫名的…），每章 >2；
  - 说教/总结式收尾（他明白了/从此…/那一刻他…），每章 ≥1；
  - 信息交代式开头（这是一…/话说/却说…），每章 ≥1；
  - 无人称感受句（令人/让人/使人…），每章 >2；
  - 突发转场词（突然/忽然/猛地/骤然…），每章 >3。
- 探测器只"探雷"：真正去味靠 `references/de-ai-flavor.md` 的八类 before/after 改写范式做二遍重写；改写后须重跑全量审计，确认 C1–C10 仍 ERROR 0、伏笔状态未乱。
- 保守设计：只抓高确定性信号、误报低；"没报警"≠"文风完美"，审美层面的灵动仍需人工判断。

## 报告格式
脚本输出 Markdown 报告：`## 汇总（ERROR n / WARN m）` + 分规则条目（章节定位 + 证据 + 误报提示）。`--json` 输出同结构 JSON 供程序消费。

## 使用纪律
- 校验是**辅助**，ERROR/WARN 由作者判真矛盾还是误报，再回写 bible/manuscript。
- 不把脚本结论当终审；它抓的是「可机器判定的漂移」，主观笔力问题不在范围内。
