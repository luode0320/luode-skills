# 世界观圣经指南（bible-guide）

bible 是**单一事实源**。所有写作与校验都从这里取数。先跑 `build_bible.py` 生成骨架，再填写。

```
python scripts/build_bible.py --project ./my-novel
# 生成 my-novel/bible/{world-bible.md, characters/, timeline.md, plot-board.md}
```

## 一、world-bible.md 字段规范

```markdown
# 世界观圣经：<书名>

## 1. 基础设定
- 类型：仙侠 / 科幻 / 都市 / 言情 / 悬疑 …
- 时代背景：
- 核心冲突：

## 2. 世界规则（确定性校验的「设定」来源）
- 规则 R1：<一句可判定规则，如「灵力耗尽者 12 时辰内无法再施法」>
- 规则 R2：<…>
> 规则要写「可机器核对」的形式（明确主体+条件+结果），别写形容词。

## 3. 力量/能力体系（如有）
- 层级：练气→筑基→金丹→…（明确每层的可观测标志）
- 禁忌：<明确禁止项>

## 4. 地理/机构
- 地名 A：定位 + 关键属性
- 机构 B：职能 + 关键人物

## 5. 结构规划（来自 planning-guide）
- 卷/章预算表（链接或内联）
```

## 二、characters/<name>.md 人物卡字段

```markdown
# 人物：<姓名（规范拼写）>
- 别名/曾用名：<无则写「无」>
- 性别/年龄：
- 外貌关键特征：<用于一致性核对，如「左手六指」「左脸疤」>
- 性格：
- 当前状态：在世 / 已故(死于第X卷) / 失踪(第X–X卷) / 流放…
- 关系网：<与谁敌/友/恋/师徒>
- 弧光：<起点→终点>
- 在场时间线：<出现卷章范围>
```

> **关键**：`姓名` 是规范拼写，consistency_audit 会据此抓名字变体；`当前状态`/`在场时间线` 供「在场性」规则核对。

## 三、timeline.md 时间线字段

```markdown
# 时间线
- T1：<绝对或相对时点> — 事件：<xxx>（出处：第X卷第Y章）
- T2：…
```
> 绝对日期用 `YYYY-MM-DD` 或 `纪元X年`；相对时间用「开篇后第N天」。供「时间线冲突」规则核对。

## 四、plot-board.md 剧情板字段

```markdown
# 剧情板
## 伏笔
- F1：<伏笔描述> — 埋于：第X卷 — 状态：待回收 / 已回收(第Y卷)
## 线头
- L1：<未结案线> — 状态：进行中 / 已收
```
> `状态` 字段供「伏笔未回收」规则核对；写作层每回收一处就改状态。

## 五、维护纪律
- 改了 manuscript 里的设定，**同步回 bible**（单向事实源）。
- 校验发现的真矛盾，先修 manuscript 再回写 bible。
- 不把 bible 当草稿本，只存「已确定事实」。
