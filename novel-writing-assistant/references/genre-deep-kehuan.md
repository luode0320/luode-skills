# 科幻 / 悬疑 深度一致性模板

本文件是 `genre-profiles.md` 中「科幻/悬疑/推理」侧重点的**深度展开**。通用核心（bible + 规划 + 写作 + 校验）见其他 references，这里只规定科幻**专属的可机判一致性规则**与对应 bible 字段约定。仙侠、言情深度模板另行成文件（分批交付）。

> 原则：科幻最容易出、也最该机器兜底的是「科技设定硬核自洽」与「物证状态前后一致」。以下规则全部**依赖用户按模板规范填写 bible**，校验器不臆造标准——标准是用户定义的科技规则与物品终态。

## 一、必填 bible 字段约定（机器可解析）

### world-bible.md（新增「科技体系」与「关键物品/设备状态」两节）
```
## 科技体系
- 规则 R20：曲速核心 在 未充能至 3 倍光速 时 禁止 启动跃迁，否则核心熔毁。
- 规则 R21：强 AI 未通过觉醒测试 不得 自主下达开火指令。

## 关键物品/设备状态
- 物品：曲速核心 | 终态：已损毁 | 损毁于：星历3015年
- 物品：量子密钥 | 终态：遗失 | 遗失于：星历3013年
```
（完整模板见 `templates/tech-system.md`）

### characters/<角色>.md（科幻常涉「实体类型」）
```
# 人物：林月
- 当前状态：在世
- 实体类型：本体（若是克隆体/AI副本/数字意识需注明，避免后文身份混淆）
- 在场时间线：卷1-卷6
```

## 二、科幻专属校验规则

| 规则 | 级别 | 检测逻辑 | 已知误报边界（需人工排除） |
|---|---|---|---|
| **C4-科技规则** | ERROR | world-bible 科技规则含「禁止/不得」动作词，正文出现该动作（兼容近义改写） | 同 C4 通用边界：需作者确认是否属例外设定（如新科技突破） |
| **C7 物证状态链** | WARN | bible「关键物品」记『终态=损毁/遗失』，正文出现该物品恢复/运转且无修复豁免词 | 损毁前章节属正常；上下文含「修复/重铸/克隆替换」豁免不报 |
| **C2 时间线冲突** | WARN | 科幻多线/跨星系叙事，时点（星历/地球年）冲突 | 倒叙/多视角时间差属正常误报 |
| **克隆/分身身份（软规则）** | WARN | 人物卡标「实体类型=克隆体/AI副本」，后文以「本体」身份行动且无声明 | 属主观判断，仅提示 |

## 三、科幻常见矛盾清单（写作时自查）

1. 科技规则前后矛盾：前文「曲速需 3 倍光速充能」，后文随手发动跃迁。
2. 物证状态断裂：曲速核心前文已熔毁，后文原样重启且无修复说明。
3. 能量守恒破坏：凭空造能、无代价复制稀缺资源。
4. 时间线错乱：跨星系通讯「即时」却设定光行时延迟；双生子年龄差未体现。
5. 克隆/AI 身份混淆：已销毁的克隆体以「原身」身份行动且未声明。
6. 设备能力跃升：某仪器前文精度不足，后文无升级描写地「精准读取」。

## 四、误报控制纪律

- C7 只报「明确恢复/运转动词 + 已记终态负面」且上下文无豁免；损毁前章节不报（WARN 提示人工确认时点）。
- 豁免词（修复/重铸/复制/克隆/替换/重建）出现即不报，避免误伤正常情节。
- 若科幻项目不登记物品状态（无「物品：」行），C7 自动跳过，不误报。
- C4 科技规则须写「主体+条件+结果」可判定形式，模糊规则会被标 WARN 并提示改写。

## 五、与其它类型的衔接

- 科幻常混合「言情」（科幻言情）：关系网一致性按 `genre-profiles.md` 言情侧重点。
- 科幻的「时间线/星历」多用星历纪年，C2 已支持「星历X年/第N天」等格式。
