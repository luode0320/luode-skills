# 类型侧重点（genre-profiles）

通用核心（bible + 规划 + 写作 + 校验）对所有类型一致。本文件只列**各类型的校验/模板侧重点**，轻量不膨胀。

## 仙侠 / 玄幻
- **世界规则权重高**：力量体系层级、修炼瓶颈、禁忌、丹药/法宝限制要写「可判定形式」（主体+条件+结果）。
- **一致性重点**：战力不崩（低阶角色突然越级需有明确契机）、地图/宗门关系网稳定。
- **C4 设定违反**：最常用规则，bible 规则表要细。
- **C6 境界倒退**：仙侠专属，人物当前境界不得无故倒退（深模板 `genre-deep-xianxia.md` + `cultivation-system.md`）。
- 模板侧重：world-bible 的「力量体系」「地理/宗门」两节。

## 奇幻 / 西幻 / 魔法
- **魔法/超自然规则**：写成「主体+条件+结果」可判定形式，归入 world-bible「世界规则」→ **C4 设定违反**。
- **种族/阵营关系**：敌对/同盟关系登记在「人物关系网」→ **C8 关系称谓冲突** 思路复用（敌对两族不应以盟友称谓互称）。
- **元素/克制链**：避免循环矛盾，以 `fantasy-magic.md` 模板登记。
- 深模板：`genre-deep-fantasy.md`（魔法体系 + 种族阵营，软自查清单为主，复用 C4/C8）。

## 科幻 / 悬疑 / 推理
- **设定硬核自洽**：科技/机制规则前后统一；悬疑重物证链与时间线。
- **C2 时间线冲突**：高权重，多线/跨星系叙事易乱（已支持星历纪年）。
- **C4 设定违反**：科幻技术规则、推理手法逻辑不可前后矛盾（写「主体+条件+结果」可判定形式）。
- **C7 物证状态链**：科幻专属，已损毁/遗失的关键设备不得在后文原样重现（深模板 `genre-deep-kehuan.md` + `tech-system.md` 规定物品终态字段）。
- **C9 线索/证据状态链**：悬疑/推理专属，已销毁/遗失的线索证物不得在后文原样重现（深模板 `genre-deep-urban-suspense.md` + `clue-board.md` 规定线索终态字段）。
- 模板侧重：timeline.md（精确）、world-bible 的「世界规则」「关键物品/设备状态」「线索/证据状态」。

## 都市 / 现实 / 职场
- **真实性**：地名/机构/职业细节贴近现实；不出现「现实中不可能」的设定。
- **C1 名字/C3 在场性**：现实题材人物多，名字变体与出场一致性易出。
- **C2 时间线**：都市文时间线密集（具体日期/星期/节假日），timeline.md 须精确；正文"周三例会""案发是周五"须对齐。
- **C8 关系称谓**：同事/上下级/亲戚/邻居等社会关系在 world-bible「人物关系网」写明，避免称谓冲突。
- **软维度自查**：地理/场所、职业/身份、证件/号码前后统一（机判误报高，以模板化自查清单交付，不自动化）。
- 模板侧重：characters 关系网、timeline 现实时间、`clue-board.md` 的「都市背景锚点」节。
- 深模板：`genre-deep-urban-suspense.md`（都市+悬疑合并，含自查清单与 C9 线索状态链）。

## 言情 / 甜宠 / 耽美
- **关系网一致性**：多角关系、情感进展节点要锁定，避免「昨天分手今天热恋」无过渡。
- **C8 关系称谓冲突**：言情专属，bible「人物关系网」标注 ex/stranger 的两人，正文却以配偶/恋人/亲属称谓指称 → WARN（深模板 `genre-deep-yanqing.md` + `relationship-map.md` 规定关系网字段）。
- **C2/C5**：情感状态变化（在一起/分手）须与时间线一致；情感伏笔（误会/身世）要回收。
- **内容安全**：亲密戏用「情感张力+留白」替代露骨（见 content-safety）。
- 模板侧重：world-bible 的「人物关系网」、plot-board 的「情感伏笔」、relationship-map 的情感弧光表。

## 历史 / 年代 / 考据 / 戏说
- **史实锚点**：真实人物/事件/制度列进 `timeline.md` 与 world-bible「世界规则」→ **C2 时间线冲突 / C4 设定违反**（例：「宋朝之前不得出现活字印刷」）。
- **软维度自查**：官职/称谓/器物符合朝代、虚构主角不与真实史事硬矛盾，以 `history-anchors.md` 模板逐条确认（机判误报高，不自动化）。
- 深模板：`genre-deep-history.md`（史实锚点，复用 C2/C4）。

## 游戏异界 / 系统流 / 网游 / 转生
- **系统面板强结构化**：角色等级/技能/属性天然可机判，是确定性校验最佳落点。
- **C10 游戏系统面板一致性**：等级倒退 ERROR（自废/重生/转生豁免）+ 未学技能使用 WARN（深模板 `genre-deep-game.md` + `game-system.md` 规定面板字段）。
- 模板侧重：world-bible 的「系统面板」节（严格 `- 角色：X | 等级：Lv.N | 已学技能：a, b` 格式，否则 C10 无法解析）。

## 通用提醒
- 类型可混合（如「科幻言情」），侧重点取交集，不另建模板。
- 任何类型都先建 bible，校验规则通用。
