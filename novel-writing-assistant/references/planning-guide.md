# 长弧规划指南（planning-guide）

适用：把「百万字」这个吓人的数字，拆成可执行的卷/章/节拍，并配字数预算。

> 说明：下文三幕结构、英雄之旅、雪弗兰节拍表均属**通用写作理论（常识性知识）**，非法规、非平台强制标准，仅供结构参考；最终结构由作者自定。

## 一、拆解层级

```
全书(百万字)
 └─ 卷 (通常 3–8 卷，每卷一个中观弧光)
     └─ 章 (每卷 30–80 章)
         └─ 节拍 (每章 3–6 个场景节拍)
```

## 二、结构参考（通用框架，非必须）

| 框架 | 要点 | 适用 |
|---|---|---|
| 三幕剧 | 建置(25%) / 对抗(50%) / 结局(25%) | 强情节商业长篇 |
| 英雄之旅 | 出发→启蒙→回归 12 阶段 | 成长/冒险/玄幻 |
| 雪弗兰节拍表 | 15 个情节点（开场、催化剂、中点、黑时刻…） | 好莱坞式类型片结构的小说化 |

**比例锚定**：用三幕比例做字数分配基线，再用 `wordcount_budget.py` 落到卷/章。

## 三、字数预算（确定性）

```
python scripts/wordcount_budget.py --total 1000000 --volumes 5 --chapters-per-volume 60
```
脚本按「卷间权重 + 章均分」输出每卷字数上限与每章建议字数。参数可配：
- `--total` 全书目标字数
- `--volumes` 卷数
- `--chapters-per-volume` 每卷章数（或 `--weights 1,1.2,1.5,1.2,0.8` 自定义卷权重）
- `--midpoint-boost` 中点卷加权（高潮卷多分）

**输出示例**（total=1,000,000, volumes=5, 每卷60章）：
```
卷1  建置   200,000 字  (章均 3,333)
卷2  发展   200,000 字  (章均 3,333)
卷3  中点   220,000 字  (章均 3,667)  ← 含高潮前奏
卷4  对抗   200,000 字  (章均 3,333)
卷5  结局   180,000 字  (章均 3,000)
```

## 四、节奏自检

- 每卷结尾应有「钩子/转折」，避免平铺。
- 每章应有 1 个明确目标（推进情节 or 深化人物 or 揭示设定）。
- 用 bible 的 plot-board 记录「埋线→回收」节奏，避免烂尾。

## 五、与校验层联动

规划产出的「卷/章结构 + 字数预算」应写回 bible（如 `world-bible.md` 的结构节），供写作层约束、校验层核对「是否严重超/欠预算」。
