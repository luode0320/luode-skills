# 数据回填诊断报告（模板）

> 使用方式：把本模板复制到 `{作品名}_数据诊断_{YYYYMMDD}.md`，按下表填入作者后台真实数据，然后运行
> `python scripts/data_diagnosis.py --input {本文件} --out {作品名}_数据诊断报告_{YYYYMMDD}.md`
> 脚本会自动生成完整报告。本模板同时可作为**未装脚本环境**下的人工填写版。
>
> 本文档为 Markdown 格式，可根据需要随时导出为 PDF / Word / HTML / TXT 等主流文档格式。

## 六、三条死命令自查

- [ ] 是否在**验证期或首秀期**修改过正文 / 封面 / 书名 / 简介？（是 → 立即停止，系统判异常降权）
- [ ] 是否断更 ≥3 天？（是 → 立刻恢复，断更三天以上流量断崖式下跌）
- [ ] 是否使用 22:00—24:00 发布？（是 → 改到 08:00—20:00，避免卡审致数据腰斩）
- [ ] 是否有 <1000 字的短章节？（是 → 合并，短章拉低完读数据）
- [ ] 是否开启过 3 万字「书荒测试」？（是 → 会分流 8 万字验证期关键流量）
