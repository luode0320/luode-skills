## 六、供需判定与差异化切口

### 6.1 过热区（需强差异化或避开）
年度情感纠葛（多女主）、流水线真假千金、无脑甜宠、纯霸总开局、传统都市重生、"开局签到"类同质开局、规则怪谈模板化批量产物。

### 6.2 均衡区
战神赘婿、都市种田、悬疑灵异、宫斗宅斗、游戏体育。

### 6.3 蓝海信号区（2026-09）
| 赛道 | 蓝海理由 |
|---|---|
| 都市脑洞 + 现实痛点 | 平台主推，量级中等但增速快 |
| 悬疑脑洞 × 克苏鲁 | 元素交叉，存量作品质量参差 |
| 无限流 + 规则怪谈 | 新锐，漫剧改编友好 |
| 历史权谋（硬核考据向） | 读者要真实感，供给不足 |
| 年代 + 现实搞钱（女频） | 中老年用户增量 + 广告单价高 |
| 乡村奋斗 / 现实逆袭 | 短剧改编转化率最高（红果真人剧榜首赛道） |
| 45+ 中老年向（家庭、健康、退休生活、怀旧） | **1.21 亿用户被严重忽视** |
| 无 CP 女性搞事业 | 标签量级 6188.5 万，需求已被验证 |

### 6.4 差异化切口四法
1. **元素交叉**：`主线赛道 + 一个非常规元素`（历史 + 基建、种田 + 克苏鲁、都市 + 规则怪谈）
2. **视角反转**：`换一个身份讲同一个故事`（反派视角、配角视角、长辈视角）
3. **机制升级**：`给旧题材一个带代价的新金手指`
4. **人群重定位**：`把同一题材写给被忽视的人群`（45+、女性无 CP、下沉市场蓝领）

## 八、选题避坑清单

- [ ] 是否落在"过热区"且没有差异化切口？
