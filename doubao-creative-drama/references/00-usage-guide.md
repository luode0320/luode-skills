# 入口速查：从哪开始、需要什么材料、术语对照

本文件面向使用者与入口路由，只回答"我现在有 X，该怎么用"和"这些缩写是什么意思"。所有执行规则、红线和输出格式仍以对应 reference 为准；本文件与 reference 冲突时以 reference 为准。

## 一、你现在有什么，就从哪里开始

| 你手里已有的材料 | 建议调用 | 下一步 |
|---|---|---|
| 只有灵感 / 题材 / 人物关系 / 一句话故事 | `01-script-creation` | `01b` 写完整剧本 |
| 已有项目档案 + 大纲，但没有完整剧本 | `01b-script-drafting` | `02` 剧本医生会诊 |
| 已有完整剧本，但不确定好不好 | `02-script-doctor` | `01b` 按采纳项改稿 |
| 剧本结构已定，但对白不够好 | `03-dialogue-expert` | `01b` 回填台词或 `05` 建资产库 |
| 剧本基本定稿，准备做图 / 视频 | `05-asset-library` | `04` AI 视频分镜 |
| 已有定稿剧本 + 资产映射 | `04-ai-video-storyboard` | `06` Seedance 适配或其他模型适配 |
| 已有 04 分镜，准备使用 Seedance / 豆包 / 火山方舟 | `06-seedance2-adapter` | 上传素材生成视频，或回查漂移 |
| 已有生成视频 / 粗剪 / 成片前时间轴 | `07-post-music-sound-design` | 找音乐、生成音乐、混音、发布前声音检查 |

跨阶段需求先补最早缺失环节。要 Seedance 提示词但还没有资产库和分镜时，先走 `05 → 04 → 06`，不跳阶段硬出提示词。

## 二、每个阶段最好提供什么材料

| 阶段 | 最好提供 |
|---|---|
| `01` 项目开发 | 题材、类型、目标平台、时长、想要的情绪、参考作品 |
| `01b` 完整剧本写作 | 项目档案、大纲、平台节奏档案、写作模式、节奏风格 |
| `02` 剧本医生 | 当前剧本版本、项目档案、想重点检查的问题 |
| `03` 台词专家 | 具体场次、角色关系、希望保留的剧情结构 |
| `05` 资产库 | 定稿剧本、项目档案、参考图、角色/场景/道具需求 |
| `04` AI 视频分镜 | 定稿剧本、资产总表、`@图N` 映射、平台节奏档案 |
| `06` Seedance 适配 | 04 分镜、`@图N` 映射、目标画幅、建议时长、是否需要音频；如已有上传素材，提供 `@图片/@视频/@音频` 编号 |
| `07` 后期声音 | 粗剪时间轴、对白时间点、发布平台、商用需求 |

材料不齐也可以开始：不影响推进时给出最小补充清单并标注【暂定】继续做，只有缺失会导致下游严重错误时才追问。

## 三、术语速查

| 术语 | 含义 |
|---|---|
| `@图N` | 资产库交给分镜使用的参考图编号 |
| `@图片/@视频/@音频` | Seedance / 豆包 / 火山方舟官方提示词中的素材引用 |
| `@Image/@Video/@Audio` | 第三方 API 或旧项目可兼容的英文素材引用 |
| `<角色名>` | 人物锚定标签，用固定句式把某张人物图里的稳定特征定义成可复用角色 |
| CH | 角色资产 |
| SC | 场景资产 / 场景母版 |
| PR | 道具资产 |
| PR 道具单实例锁 | 场景/首帧中已有某道具且又上传 PR 图时，锁定为同一件物体，防止生成第二个同款道具 |
| ST | 视觉风格锁定卡，用于统一项目风格、媒介类型、人物审美、场景审美和画面质感 |
| CL | 光影设计卡 |
| NP | 风格防跑偏负面词包，用于约束人物、场景和画面质感不要跑到错误审美 |
| CR | 人群 / 群演调度卡 |
| SCV | 场景多角度空间包，含 PLAN 和 V01-V04 空场角度图 |
| MAP | 调度图，用于人物点位、移动路线、摄影机安全区 |
| SB | 空间侧别锁定卡，用于避免窗内外、柜台内外、车内外等穿帮 |
| 摄影机行为锁 | 把固定、手持、跟拍、退拍、推拉、横移、环绕、焦点转移等写成可执行摄影机位置、距离、方向、速度、稳定程度和禁止项 |
| 景深与焦点锁 | `04` / `06` 必填字段，写清浅/中/大景深、焦点起点落点、禁止跑焦对象 |
| 软时间节奏 | 不写硬时间戳，只写镜头顺序、前中后段、每镜约多少秒、最后一镜稍停等节奏参考 |
| C 导演轨纯净版 | 默认输出格式，9 字段 + 一行四段镜头轨，7 镜可控在 1900 字内 |
| 一行四段 | 每镜压缩为 `[功能标签] \| 镜头/焦点 \| 动作/台词 \| 光影/转接`，替代旧版 11 字段逐行展开 |
| 素材编号一致性闸门 | 交付前强制检查，同一角色/场景/道具在所有镜头中必须使用同一 `@图片N` 编号 |
| 衔接可见化 | 禁止 `接下一大分镜` 等模糊衔接，必须写成模型可执行的动作转接或段末画面状态 |
| FF | 首帧图 / 首帧需求卡，只锁定第 0 秒 |
| 视频延长 | 同场景顺延时把上一段成片作为 `@视频` 继续自然延长；第三方接入端可用 `@Video` |
| A/B/C 首帧风险 | A 必须首帧，B 建议首帧，C 可不用首帧 |
| Must Keep | 生成时必须保持的角色、场景、道具、关系和动作 |
| Avoid | 生成时必须避免的问题 |

## 四、常用调用语

```text
使用 doubao-creative-drama，帮我从 0 到 1 开发一个竖屏短剧项目。
```

```text
使用 doubao-creative-drama，下面是我的项目档案和大纲，请开始写完整剧本，模式=小说化，节奏=短剧，分集=是。
```

```text
使用 doubao-creative-drama，下面这场戏只做台词诊断，不改剧情。
```

```text
使用 doubao-creative-drama，根据项目档案和剧本建立完整资产库。
```

```text
使用 doubao-creative-drama，把这段 04 分镜转成 Seedance 2.0 提示词包，按 9:16、每段 4-15 秒输出。
```

```text
使用 doubao-creative-drama，视频都生成完了，帮我做后期 BGM 和声音设计，输出 Cue Sheet、音乐搜索词和 AI 音乐生成提示词。
```
