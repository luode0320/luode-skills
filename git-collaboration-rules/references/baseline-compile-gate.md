# 代码项目最基本编译闸门

本文件是“提交前必须编译通过”的唯一细判据；`scripts/pre_commit_gate.sh` 的第 6 步实现本文件。

### 判定口径

- “代码项目”只看仓库根的构建标记文件，不看文件扩展名：命中下表任一标记即为代码项目。
- 一个仓库命中多个标记时，逐项执行，全部通过才放行。
- 仓库根无任何标记时视为非代码项目，输出 `N/A` 后放行，避免规则误伤纯文档 / 纯 skill 资产仓库。
- 编译通过只证明代码能编译，**不证明功能可用**；功能、接口、页面验证仍由测试类 skill 负责。

### 按标记选择编译入口

| 项目标记 | 编译入口 | 说明 |
| --- | --- | --- |
| `go.mod` | `go build ./...` | 包级编译，不产出提交物 |
| `Cargo.toml` | `cargo check` | 类型与借用检查，不产出二进制 |
| `tsconfig.json` | `tsc --noEmit -p tsconfig.json` | 优先 `node_modules/.bin/tsc`，缺失时 `npx --no-install` |
| `package.json`（无 `tsconfig.json`，且定义了 `build` 脚本） | `npm run build` | 以项目自定义构建作为编译入口 |
| `pyproject.toml` / `setup.py` | 对 staged `.py` 文件做 `ast.parse` | 只做语法编译检查，不执行导入 |

### 硬约束

- **禁止联网安装工具链**：TypeScript 入口使用 `npx --no-install`，Dart/其它需要拉取依赖的入口一律不用；工具链缺失时直接阻断。
- **工具链缺失即阻断**：命令不存在时输出 `BLOCK: ... 缺少命令 ...`，不得静默跳过或记为 `N/A`。
- **超时即阻断**：默认 600 秒，可用环境变量 `COMPILE_GATE_TIMEOUT` 覆盖；`timeout` 不可用时退化为不限时执行，并在证据中标注。
- **读索引而非工作区**：Python 语法检查用 `git cat-file blob ":<path>"` 读取暂存版本，避免“暂存了坏代码但工作区是好的”漏检。
- **不写产物**：Python 用 `-B` 关闭字节码，Go 用 `go build ./...`（不指定输出路径），避免污染工作树。

### 失败处理

- 退出码 19 表示编译闸门阻断；先用同一条命令手工复现，再修复代码或补依赖，不得绕过脚本直接 commit。
- 修复后必须重跑同一条编译命令并取得退出码 0，再重新执行 pre gate。
- 编译失败属阻断项，不得用 `--no-verify`、临时删除标记文件或改 `COMPILE_GATE_TIMEOUT` 等方式规避。

### 与其它规则的边界

- 本闸门不替代 staged 基础代码核查、基础验收、真实测试与 `6-review` 风格回归。
- 本闸门不判断编译告警、lint 或格式问题；这些仍由基础核查与项目既有检查负责。
- 非代码仓库（如仅有 `package.json` 但无 `build` 脚本的纯 skill 资产仓库）跳过编译闸门，但 staged 基础核查照常执行。
