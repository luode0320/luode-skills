# 回测结果 → TradingView 看板

把任意回测系统的运行结果，转成一张可在浏览器离线打开、可交互的 TradingView 风格看板。
适用标的与策略类型不限：现货/合约网格、趋势、信号策略；加密/股票/期货皆可。

## Skill 作用与适用场景

- **适用**：已有可复现的回测结果（基准数值 + 逐笔成交或至少净值曲线），需要给用户看"钱怎么走的"。
- **不适用**：实时行情看板；需要服务端渲染/多人协作的看板；只要一张静态图（用截图或简单图表工具更轻）。
- 判断口径：需求里出现"看板 / 图表 / 曲线 / 买卖点 / tradingview"，且产物应当是**可交互文件**而非一张图。

## 核心架构（务必分两层，不要混写）

| 层 | 产物 | 职责 |
|---|---|---|
| 导出层 `<EXPORT_SCRIPT>` | 紧凑 JSON | 调用**真实回测引擎**重放一遍，记录绘图所需数据 |
| 渲染层 `<BUILD_SCRIPT>` | 单文件 HTML | 读 JSON + 内联图表库 → 自包含看板 |

导出 JSON 建议结构（日期数组共用，数值用对齐数组，体积最小）：

```json
{
  "meta":   {"start":"<YYYY-MM-DD>","end":"<YYYY-MM-DD>","initial_cash":0,"symbols":["<SYM>"]},
  "summary":{"final_equity":0,"nav_final":0,"nav_return_pct":0,"annual_pct":0,"max_drawdown_pct":0,
             "grid_profit":0,"total_fee":0,"close_trades":0,"win_rate":0},
  "days":   ["<YYYY-MM-DD>", "..."],
  "nav":    [0.0, "..."], "eq": [0.0, "..."], "dd": [0.0, "..."],
  "assets": {"<SYM>": {"ohlc":[[o,h,l,c,vol],"..."], "equity":[0.0,"..."],
                       "trades":[[dayIndex,"b"|"s",price,profit],"..."], "params":{} }}
}
```

## 铁律（实测教训，按重要性排列）

1. **记录层不得重写引擎逻辑**：必须 import/调用生产引擎，用**子类覆写成交方法**或回调来记录成交。
   任何"顺手优化"都会让数字偏离基准，看板即失去意义。这是最容易犯且后果最严重的错误。
2. **导出后必须逐项对照基准**：期末权益、净值倍数、最大回撤、逐标的明细，容差按资金量级设（如 0.05U）。
   不一致先修导出层，**不要去调看板**。
3. **Lightweight Charts v4 与 v5 API 不兼容**（最常踩的版本坑）：
   - v4：`addCandlestickSeries()` / `addAreaSeries()` / `addLineSeries()` / `series.setMarkers()`
   - v5：`addSeries(CandlestickSeries, opts)`
   锁定版本号并把库文件内联，**不要随手升 CDN 版本**。
4. **轴精度陷阱**：chart 级 `localization.priceFormatter` 会**覆盖** series 的 `priceFormat`，两处同时设会打架。
   正解：只用 series 级 `priceFormat`，并按价格量级自适应（≥1000→0 位、≥100→1 位、≥1→2 位、否则 4 位）。
   否则库会按数据精度（如 8 位小数）推断，轴标签出现 `72.00000` 这类噪声。
5. **负价格刻度**：价格轴为成交量留出 `scaleMargins.bottom` 空间时，轴会延伸到负值。
   用 series 的 `autoscaleInfoProvider` 把 `priceRange.minValue` 钳到 0。
6. **回撤图倒挂**：`invertScale` 是 **chart 级** `rightPriceScale` 选项，**不是 series 选项**；数据传正值，
   轴反转后 0 在顶部、回撤越深越向下。
7. **时间轴一律用业务日字符串 `'YYYY-MM-DD'`**，禁用 UNIX 时间戳——规避时区偏移导致的日期错位。
8. **markers 的时间必须命中 K 线数据中真实存在的日期**，否则标记静默不显示（最难排查的一类"空图"）。
9. **多图联动**：多个 chart 用 `subscribeVisibleLogicalRangeChange` + `setVisibleLogicalRange` 同步，
   加锁标志防止互相触发死循环；`fitContent()` 只在对齐后调用，避免各图范围漂移。
10. **单文件交付**：图表库与数据全部内联，保证离线可开、单文件可转发（自包含优先于体积）。
11. **胜率解读是交付义务**：移动止盈/只止盈不止损类策略的"平仓全盈利"是**机制属性**（未达目标的仓位不平仓），
    不是信号准确率。交付说明里必须点明未实现浮亏与最大回撤，否则会被误读为"稳赚"。
12. **大样本渲染要控量**：分钟级数据先聚合成日线（`dayIndex = minuteIndex // 1440`）；成交明细表默认只渲染
    最近 200–300 笔，避免 DOM/JSON 膨胀。

## 默认执行流程

1. **确认基准**：找到最近一次回测的结果 JSON，或重跑一次引擎拿到权威数值（后续所有校验以它为准）。
2. **写导出脚本** `<EXPORT_SCRIPT>`：
   - 复用引擎：子类覆写 `buy/sell` 记录成交；**用引擎实际使用的价格口径**（如 open），
     不要为了图好看换成 close —— 否则结果无法与基准对齐。
   - 同一遍遍历同时产出：日线 OHLCV 聚合 + 逐笔成交 + 日度净值/权益/回撤。
   - 落盘紧凑 JSON。
3. **跑导出并对照基准**（脚本内置对照打印：逐标的期末值 + 组合合计，容差内才算通过）。
4. **写渲染脚本** `<BUILD_SCRIPT>`：读 JSON + 内联图表库 → 输出单文件 HTML。
   版面建议：顶部 KPI 卡片 → 价格图（蜡烛 + 成交量 + 买卖标记 + 标的 tab）→ 净值面积图 + 倒挂回撤图
   → 多标的权益曲线 → 绩效/参数表 → 成交明细表。
5. **无头验证渲染**（见下节命令），确认：无 JS 报错（页面元素是否被填满）、轴刻度正常、买卖标记出现、tab 切换生效。
6. **交付**：单文件 HTML（可交互）+ 一张静态预览图 + 数据 JSON。

## 无头渲染验证（推荐做法）

```sh
"<chrome 或 edge 可执行文件>" --headless=new --disable-gpu --hide-scrollbars \
  --virtual-time-budget=15000 --window-size=1560,2560 \
  --screenshot="<out.png>" "file:///<abs>/dashboard.html#<SYMBOL>"
```

- Windows 常见路径：`C:\Program Files\Google\Chrome\Application\chrome.exe`、
  `C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe`
- `--virtual-time-budget` 是关键：等 JS 把图表画完再截图，否则截到空框架。
- **若 CDP 类浏览器自动化工具（agent-browser 等）在目标机器上启动即挂起**（无任何输出、超过数分钟），
  不要反复重试，直接切到上面的 headless 截图方案。
- 让看板支持 `#<SYMBOL>` hash 深链，既便于验证单标的视图，也便于分享。

## 参数、边界与常见误解

- 看板是**展示层**：不改策略、不改参数、不重跑历史，只忠实呈现引擎结果。
- K 线颜色遵循用户市场习惯（中国市场：**涨红跌绿**），不要默认套用欧美配色。
- 网格加仓触发价、止盈目标等参数应写进看板参数表，让图与策略可对照。
- 买卖标记过多时（数千笔）提供"显示/隐藏标记"开关，避免图形糊成一片。

## 权责边界与不负责事项

- 不负责回测引擎的实现、参数搜索与优化（那属于策略/回测类 skill）。
- 不判断策略是否有效、是否应该上实盘。
- 不修改生产回测结果文件；导出数据是**只读消费**。
- 不替代实时监控/交易执行系统。

## 执行通过 / 驳回标准

- **通过**：导出的关键数值与基准逐项一致（容差内）；无头截图确认图表正常渲染、标记存在、切 tab 生效；
  交付单文件 HTML 可直接打开。
- **通过**：踩坑点（版本 API、轴精度、负刻度、invertScale、时区、markers 命中）已在实现中规避。
- **驳回**：重写了一份"看起来一样"的引擎逻辑，数字与基准不符。
- **驳回**：只给静态图或截图，没有可交互产物。
- **驳回**：交付说明回避策略风险（未实现浮亏、回撤），只报收益率。
