# File Organizer

整理指定文件夹中的文件，按类型自动分类到子文件夹中。

> **安全第一（红线）**：本 skill 处理的是用户个人文件，移动即改动用户环境。默认只做「扫描 → 报告 → 用户确认」；未经用户逐项确认，禁止执行任何移动/重命名/删除动作。

## 适用边界

- **做**：扫描文件夹生成分类报告、按确认后的规则移动文件到分类子文件夹、输出整理报告。
- **不做（转交）**：
  - 删除/清理垃圾文件 → `unclecheng-garbage-cleanup-master`（垃圾清理大师）或 `ubuntu-wsl-system-cleanup`
  - 系统目录/桌面/下载整盘递归清理 → 一律拒绝（见下方红线）
  - 本 skill 只整理（移动归类），**不删除任何文件**。

## 工作流（5 步，移动前强制确认）

### 第 1 步：确认目标目录与边界

- **输入**：用户指定的目标文件夹。
- **动作**：确认目录存在且可读；向用户明确整理范围（仅该目录顶层文件，不递归子文件夹、不动系统目录）。
- **输出**：整理范围确认（目录 + 边界声明）。

### 第 2 步：扫描（只读）生成报告

- **输入**：已确认的目标目录。
- **动作**：列出全部文件（不处理已有子文件夹），按 `references/category-map.md` 分类规则匹配扩展名。
- **输出**：分类报告——每个待移动文件：原路径 → 目标子文件夹 → 新路径；以及「不移动项」（已有子文件夹、无扩展名文件、目标同名冲突项）。

### 第 3 步：用户确认（强制闸门）

- **输入**：第 2 步分类报告。
- **动作**：展示完整清单（原路径 → 目标路径），标注冲突与风险项。
- **闸门【必确认】**：未经用户逐项/批量明确确认，不执行任何移动。用户可调整：排除某些文件、修改类别、改子文件夹名。
- **输出**：用户确认后的最终移动清单。

### 第 4 步：分批执行移动

- **输入**：确认后的移动清单。
- **动作**：按确认清单执行移动；**每批最多 10 个文件**，每批后验证结果；目标子文件夹不存在则先创建；目标同名文件加数字后缀（`file(1).pdf`）避免覆盖。
- **输出**：每批执行结果（成功/失败明细）。

### 第 5 步：输出整理报告与校验

- **输入**：全部批次执行结果。
- **动作**：汇总报告——移动成功数、失败数、冲突处理、剩余未处理项；建议用户抽查移动结果。
- **输出**：最终整理报告 + 未处理项清单。

## 分类规则

默认分类表见 `references/category-map.md`（权威源）；SKILL.md 内联速查：

| 类别 | 子文件夹名 | 扩展名 |
|------|-----------|--------|
| 文档 | 文档 | .pdf, .docx, .doc, .md, .txt, .pptx, .ppt, .xlsx, .xls |
| 图片 | 图片 | .png, .jpg, .jpeg, .gif, .bmp, .svg, .webp, .ico |
| 压缩包 | 压缩包 | .zip, .rar, .7z, .tar, .gz, .mrpack |
| 安装程序 | 安装程序 | .exe, .msi, .msu |
| DLL文件 | DLL文件 | .dll |
| 代码 | 代码 | .java, .py, .js, .ts, .html, .css, .json, .xml, .yaml, .yml, .c, .cpp, .h, .go, .rs |
| 日志 | 日志 | .log |
| Minecraft | Minecraft | .litematic, .schematic |
| 其他 | 其他 | 以上未覆盖的扩展名 |

自定义规则优先级高于默认表（用户指定「类别 → 子文件夹名 → 扩展名」三元组）。

## 边界条件与错误恢复

- **权限不足**（目录只读/无写权限）：如实报告错误，不绕过权限（不 sudo、不强制改权限），提示用户以合适权限重试。
- **移动失败**（文件被占用/跨盘失败）：保留原文件不动，记录失败项，最后汇总给用户；已成功的批次不回滚。
- **同名冲突**：目标已存在 → 加数字后缀，不覆盖原文件；冲突较多时先列出再继续。
- **中途中断**：重新扫描时以「当前磁盘实际状态」为准生成新报告（已移动的文件不再出现），不依赖上次记忆。
- **误操作恢复**：移动前建议用户先备份目标目录（特别是批量整理前）；整理后 7 天内发现问题可手动移回（本 skill 不自动回滚删除）。
- **危险操作拒绝**：涉及系统目录、`AppData`、`Library`、`~/.config` 等配置目录，或用户要求「删掉所有 X 文件」「全盘清理」时，一律拒绝执行并解释原因。

## 退出机制

用户输入「结束」→ 停止，回复「文件整理完成。」；第 3 步确认未通过前不执行任何移动动作。

## 约束

- **只整理不删除**：本 skill 任何步骤都不删除文件；需要删除时转交垃圾清理类 skill。
- **每批 ≤ 10 个文件**，每批后验证，任何失败即停止该批并汇报。
- 移动清单、冲突处理、失败明细必须完整呈现给用户，不静默跳过。
- 整理范围默认仅目标目录顶层文件，不递归子文件夹、不跨盘自动移动（除非用户明确要求）。
