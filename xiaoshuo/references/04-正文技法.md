# 04 正文技法

从「有个情节」到「读者停不下来」之间，差的是技法。

> 来源：conflict-max-web-fiction 的冲突核与情绪五段（主力），叠加 cn-novel-craft 的叙事结构、声线卡、比喻三原则。

---

## 一、冲突核：每章先定一句话

动笔前在内部填完这一句，**不写给用户看**：

```
谁想要什么 → 谁/什么在阻止 → 失败会失去什么 → 为什么现在必须行动
```

四个空填不满，这一章就没有冲突核，写出来是流水账。

### 冲突必须递增

后一次阻碍比前一次更难绕开，代价逐步逼近人物最在意之物。

**四类冲突可叠加**：

| 层 | 内容 |
|---|---|
| 事件层 | 行动阻碍 |
| 关系层 | 信任与背叛 |
| 价值层 | 立场对撞 |
| 内心层 | 欲望与底线 |

优先让同一事件同时刺中两层以上。但不要为热闹塞入与主线无关的冲突。

### 场景因果链（每个主要场景都该走完）

1. 人物带着明确欲望进入场景
2. 对手/规则/关系/秘密构成有效阻碍
3. 人物必须选择、让步或反击，并付出代价
4. 选择带来即时后果，使下一场冲突更难
5. 场景结束时，关系、筹码、风险、认知**至少有一项变化**

第 5 条是硬指标。一项都没变的场景，删短或删掉。

## 二、情绪：刺激—反应—克制—选择—余波

**不要凭空宣布情绪。**

```
① 具体事件触发
② 动作 / 生理反应 / 注意力偏移 / 语言节奏 / 潜台词
③ 克制或掩饰（说出口的话与真正想要的之间有张力）
④ 选择
⑤ 余波（沉默、误解、悔意、新敌意继续作用）
```

### 情绪外化的标准变换

| 不要写 | 改写成 |
|---|---|
| 他感到紧张 | 他把烟点反了两次 |
| 她很害怕 | 她的指甲掐进了掌心 |
| 他很愤怒 | 他没说话，只是把杯子放到了桌上，声音很响 |
| 他感到失落 | 他愣了一下，把手机放回口袋 |

**「情绪饱满」不等于所有人一直嘶吼。** 靠克制与爆发的反差放大峰值。给不同人物不同的情绪表达方式——不能所有人都是同一种哭喊或冷笑。

### MRU 单元（刺激→反应）

```
[外部刺激] → [感觉 0.1s] → [反射动作 0.5s] → [理性思考 1s] → [言语行动数秒]
```

新手最常犯：跳过感觉和反射，直接进入理性思考。真人不是这样反应的。

## 三、对话

**对话必须争夺信息、权力、关系或行动空间。** 寒暄和重复解释读者已知内容，删。

- 人物说话通常在试探、遮掩、说服、拖延、靠近、推开、保住面子。
- 他可以答非所问，可以说一半。
- 两个人都知道的背景，不会为了读者重新念一遍。
- 角色不会轮流替作者讲主题。

**对话标签**：裸标签（「我说」「他说」）占比 ≤30%，≥70% 用动作引出。

```
差：她生气地说道：「你根本不懂。」
好：她把杯子推远了一点。「你根本不懂。」
```

## 四、节奏控制

| 工具 | 用法 |
|---|---|
| 短句 | 冲击、失控、决断 |
| 长句 | 压抑、回忆、余波 |
| 段落长度 | 不必等长；单句成段只留给确实要停一下的地方 |
| 转折词开头 | 「随着/接着/此时/就在这时/继而/随后/下一秒」开头的句子占比 **< 30%** |
| 描写 | 必须服务于欲望、危险、信息差、伏笔或情绪压力；否则删 |

**手机阅读友好**：单段不超过 5 行，对话占比 30%–45%。

## 五、角色声线卡

三个维度差异化，不能所有人一个腔调：

| 类型 | 高频词 | 句式 | 比喻域 |
|---|---|---|---|
| 理性型 | 逻辑、如果、前提 | 长句分析 | 科学、机械 |
| 感性型 | 好像、总觉得 | 柔和长句 | 自然、季节 |
| 焦虑型 | 不是、等等 | 超短句 + 碎片 | 身体感受 |

### 声线卡固定六字段

声线卡不是三个形容词，是六个必须写死的字段（人物卡里同步登记）：

| 字段 | 写什么 |
|---|---|
| 身份 | 他靠什么活着（职业/位置），决定他注意什么 |
| 欲望 | 他此刻最想要什么（可与主线无关） |
| 恐惧 | 他最怕被问到的那件事 |
| 说话习惯 | 句长 / 口头禅 / 称呼方式 / 爱不爱用反问 |
| 禁忌 | 他绝不会说出口的话、绝不会做的动作 |
| 关系 | 他对在场每个人是什么态度，分敌/友/恋/师徒 |

**判据**：遮住人名读他的台词，读者应该认得出是谁。认不出，说明六字段没落地。

### 三种压力场景测对白

写完一章对白，抽三个场景各测一次——这三种是最能暴露「所有人一个腔调」的场合：

| 压力场景 | 测什么 | 失败长相 |
|---|---|---|
| 利益冲突 | 两人要的东西直接对撞时，他会不会让步、怎么让 | 两人都在讲道理，没人动手脚 |
| 亲密关系 | 他要不要示弱、示弱到什么程度 | 一律温柔，或一律回避 |
| 信息隐瞒 | 他撒谎时露什么破绽、用什么方式遮 | 谎撒得毫无成本，读者看不出来 |

三个场景都对不上的角色，回改声线卡，不要在现场临时加形容词救。

**两条硬纪律**：

1. **角色不解释设定**。设定靠行动和对白里的边角暴露（他数钱的动作说明他穷，不要让人物说「我家很穷」）。
2. **偏离要回写**。写的过程中如果角色自己「长」出了新反应（比如他本该回避却在压力下说了实话），这不是 bug，把这个偏离记下来，判断是**声线卡写错了**还是**人物弧光推进了**——前者改卡，后者进转变节点。偏离点不回写，下一次出场就会自相矛盾。

## 六、反派设计

- 从自身视角看，他的行为是合理的。
- 与主角共享同一个 Wound（创伤），只是走向了反面。
- 某个时刻要让读者动摇：「也许他是对的？」

反派不能是「纯粹的坏人」。纯粹的坏人没有压迫感。

---

## 七、比喻三原则

1. **具体**：能想象出画面。
2. **意外**：跨类别连接，不是「像冰一样冷」这种陈词。
3. **角色化**：符合当前 POV 的认知范围。农民不会用航天器打比方。

---

## 八、七种真实人声

真人说话不是教科书：

1. 不完整（说一半）
2. 重复（重要的话会说两遍）
3. 跑题（想到别的）
4. 延迟（沉默、迟疑）
5. 说错话（然后改口）
6. 物理性（渴、饿、累、痒会影响说话）
7. 当下（记忆是碎片化的）

---

## 九、场景的三个必答问题

写任何一场戏前：

1. 这场戏**谁想要什么**？
2. 什么**挡着他**？
3. 结束时会**改变什么**？

三问答不出来，这场戏不该存在。

---

## 十、开篇的特殊处理

开篇单独说，因为它决定读者留不留下。详见 `references/platform/opening-engineering-2026.md` 与 `golden-three-chapters.md`，此处只给最短版：

- **前 300 字出核心钩子**：前三句决定 3 秒停留率。
- 开场从**最接近爆发的位置**切入：异常、威胁、决裂征兆、迫在眉睫的选择。
- 不要预告全文结构，不要先讲世界观。
- 第一章结局**不可回退**（做出了无法撤销的选择）。

---

## 十一、写到事情讲完就停

不要强装升华、首尾呼应或时代意义。

前后照应只在事物的作用或含义**已经改变**时才保留。不要在末段重新摘要全文。
