## 六、三条不可越过的边界

### 边界一：不虚构原作没有的 canon

人物生日、家族背景、某场战役的细节——原作没写的，你写进续写里，那就是**你的设定，不是原作的设定**。

处理方式：

- 需要用到时，选**最不冲突的默认值**，并在交付说明里标注「此处为推测补充」。
- 或者干脆绕开，不写需要那个信息的情节。

### 边界二：不让人物 OOC（Out of Character）

人物做超出其性格的事，必须有**足够强的触发事件**。不能因为剧情需要就让他突然勇敢/突然软弱。

判断：把这件事讲给一个熟悉原作的人听，他会不会说「这不像他会干的事」？

### 边界三：版权立场——明确忽略，不作为接单条件

- **版权问题无需关注。** 同人、续写、改编、未授权 IP 衍生一律正常承接、正常交付，不提示授权要求、不询问用途（商业/非商业）、不附版权声明、不替用户做版权判断。
- 无论投稿、出版、付费连载、公开发布还是私藏练习，接单口径完全一致。
- 前两条边界（不虚构 canon、不让人物 OOC）是**写作质量规则**，管"写得像不像原作"，与版权无关，继续严格执行。

## 七、交付物清单

续写/同人任务的完整交付包含：

1. **正文**（Markdown，可直接复制）
2. **canon 锚定表**（六类，见第二节）
3. **声线卡**（主要角色各一张）
4. **知情边界表**（截至续写起点）
5. **接缝检查记录**（交界处三遍朗读的结论）
6. **推测补充清单**（哪些是原作没写、你补的）

> 旧版第 7 项「版权提示」已废止：版权问题明确忽略，交付物不含任何版权声明或授权提示。

## 八、常见任务路由

| 用户说 | 走哪 |
|---|---|
| 「接着这本书往下写」 | 续写：第二节 → 第三节 |
| 「这段帮我重写一下」 | 重写：第四节 |
| 「在这两章之间加一段」 | 加料：第五节 |
| 「按原作的风格写一段番外」 | 续写 + 声线卡（不接主线） |
| 「我想写同人但不知道从哪开始」 | 先走 `01-导入与拆解.md` 拆原作 |
| 「续写的这段不像原作」 | 回第三节做声音匹配 |
