# 都市 / 悬疑 深度一致性模板

> 适用：现代都市、职场、商战、悬疑、推理、刑侦类小说。
> 与通用流程的关系：本模板不新增「流程」，而是把通用规则（C2/C4/C5/C7/C8/C9）在都市/悬疑语境下的**字段约定与自查清单**固化下来，让确定性校验器能真正发挥作用。

## 一、都市文重点维度（确定性偏弱 → 以「复用 + 自查」为主，不强行加硬规则）

| 维度 | 复用规则 | 字段约定 / 自查清单 |
|---|---|---|
| 现代时间线密集（具体日期、星期、节假日） | C2 时间线冲突 | timeline.md 精确记「周X/几月几日」，正文涉及"周三例会""案发是周五"时核对；月份天数、闰年、星期推算自行核对 |
| 社会关系称谓（同事/上下级/亲戚/邻居） | C8 关系称谓冲突 | world-bible「人物关系网」节写明职业关系：`林越 — 周野：上下级（直属）`、`苏禾 — 林越：邻居`；C8 会校称谓互斥（如标"前任"却称"丈夫"） |
| 地理位置 / 场所一致性 | （暂无硬规则，人工核对） | 自查：同一栋楼/小区/公司名称前后统一；跨城通勤时间合理 |
| 职业 / 身份一致性 | （暂无硬规则，人工核对） | 自查：人物职位、单位、专业前后不变；证书/执照类设定不前后矛盾 |
| 证件 / 号码一致性 | （暂无硬规则，人工核对） | 自查：身份证号、车牌、合同编号若写出，前后务必一致（机判需精确字符串，误报高，故不自动化） |

> 设计原则：都市维度多为"软一致"，强行机判误报高，故以**模板化自查清单**交付，符合"低误报、真实可机判"红线。

## 二、悬疑 / 推理重点维度（确定性较强 → 有硬规则 C9）

### 1. 线索 / 证据状态链（C9，WARN 级）
- **字段约定**：world-bible.md 加「线索/证据状态」行：
  `- 线索：带血手帕 | 终态：已销毁 | 销毁于：案发现场焚化炉`
  支持「线索/证物/证据」三种写法；终态含「销毁/损毁/遗失/丢失/灭失/焚毁/湮灭/粉碎/没收/封存」之一即纳入监控。
- **触发**：bible 记线索 X 终态=销毁/遗失，正文却出现 X「重现/被找到/被检验/被出示」且无豁免词 → WARN。
- **豁免词**（不报）：伪造 / 调包 / 复制 / 仿制 / 新发现 / 另寻 / 重新取得 / 新线索 / 新证据 / 备份 / 复印件。
- **为什么 WARN 不 ERROR**：线索在更早章节已出现属正常叙事，纯文本无时点，需作者确认；定 WARN 避免误伤。

### 2. 推理逻辑前后一致（C4，ERROR 级）
- world-bible「世界规则」或单独的 `clue-board.md` 写推理硬规则，须「可判定形式」：
  `凡指纹匹配者 不得 被排除嫌疑` / `密室须从内部反锁，外部无法开启`。
- 正文出现被禁动作（如"凶手从外部打开了反锁的密室"）即触发 C4。

### 3. 时间线 / 不在场证明（C2，WARN 级）
- timeline.md 精确记案发时点、各嫌疑人 alibi 时点；C2 会校验"正文断言的日期"与 bible 冲突。
- 悬疑特有：若凶手 alibi 写"案发时在外地"，正文却让其出现在案发现场对话 → 用 C2 或人工核对。

### 4. 红鲱鱼 / 误导性线索回收（C5，WARN 级）
- plot-board.md 把假线索标记为伏笔：`F3：旧怀表是凶手遗落 — 埋于：第3章 — 状态：待回收`。
- 若到结局仍未揭示"是真线索还是误导"，C5 会持续 WARN，提醒回收。

## 三、都市/悬疑自查清单（写作前过一遍）

- [ ] timeline.md 是否记了关键日期/星期，并与正文"周三例会"等说法对齐（C2）
- [ ] world-bible「人物关系网」是否写清同事/上下级/亲戚/邻居，称谓会冲突吗（C8）
- [ ] 线索/证据是否登记终态，避免"已焚毁的物证又冒出来"（C9）
- [ ] 推理规则是否写「可判定形式」，而非形容词（C4）
- [ ] 红鲱鱼/假线索是否在结局回收或揭示（C5）
- [ ] 地名/单位/职位/证件号是否前后统一（人工）

## 四、调用方式

- 写都市/悬疑前，先 `genres/genre-profiles.md` 看类型段，再读本模板与 `templates/clue-board.md`。
- 建库后用 `scripts/consistency_audit.py --bible <dir> --ms <dir>` 跑 C1–C9 全量校验。
- 误报处理：WARN 级（C2/C5/C7/C8/C9）多为"需人工确认时点"，按 hint 排除；ERROR 级（C3/C4/C6）须修。
