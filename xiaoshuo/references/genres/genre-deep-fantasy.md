# 奇幻小说深度一致性模板

## 为什么单列
奇幻的核心是「魔法/超自然体系」与「种族/阵营关系」。前者需写成可判定规则（C4），后者易在对话称谓中悄悄改写（C8 思路）。

## bible 字段约定
- `world-bible.md` 的「世界规则」：魔法规则写成「主体+条件+结果」可判定形式 → **C4 设定违反**。
- `world-bible.md` 的「人物关系网」：种族/阵营敌对关系登记 → **C8 关系称谓冲突** 思路复用（敌对两族不应以盟友称谓互称）。
- 建议新增「魔法/力量体系」节（见 `templates/fantasy-magic.md`）。

## 与 C4 的配合
例：规则 R1：魔力枯竭者 禁止 再次施法；正文「他魔力已空，却再度施放火球」→ ERROR。

## 自查清单（软规则）
1. 同一魔法规则前后一致、无近义改写冲突
2. 种族/阵营关系在称谓中未被改写
3. 元素克制链无循环矛盾
4. 力量体系成长曲线无突兀跳变

## 误报控制
- 模糊形容词式设定无法机判，必须写「可判定形式」才进 C4。
- 种族关系未登记不误报。

## 分诊触发
用户提到：奇幻 / 魔法 / 种族 / 阵营 / 西幻 / 龙与地下城 / 力量体系 → 路由本模板 + `fantasy-magic.md`。
