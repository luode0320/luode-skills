# 言情 / 甜宠 / 耽美 深度一致性模板

> 类型侧重点见 `genre-profiles.md` 的「言情」段。本文件给出**可机判的 bible 字段约定**与**关系一致性规则**，配合 `templates/relationship-map.md` 使用。

## 一、言情最易崩的三类一致性

| 风险 | 表现 | 本技能对应机制 |
|---|---|---|
| 关系状态漂移 | 「昨天分手今天叫老婆」无过渡 | **C8 关系称谓冲突**（WARN） |
| 时间线错位 | 情感节点（表白/分手）与 timeline 矛盾 | **C2 时间线冲突**（WARN） |
| 情感伏笔断头 | 误会/身世埋了不回收 | **C5 伏笔未回收**（WARN） |

> 言情的「情感弧光强度/人物是否 OOC」属主观笔力，不在机判范围；机判只抓**可锚定的事实矛盾**。

## 二、bible 字段约定（决定 C8 能否扫描）

在 `world-bible.md` 增加「人物关系网」节，格式严格如下（C8 解析依赖此格式）：

```
## 人物关系网
- 林月 — 顾言：前任（已分手，第2卷末）
- 林月 — 苏白：现任恋人（第4卷确定）
```

- 标签须含可机判关键词（前/旧/ex、妻/夫/配偶、恋/男友/女友、父/母/子/女、陌生…），详见 `templates/relationship-map.md`。
- **不要**在一行里写互斥关系（如「前任妻子」）——拆成两行不同阶段的时点记录。

## 三、C8 关系称谓冲突（WARN 级）

- **判据**：bible 标注 A—B 为 `ex`/`stranger`，正文却以 `spouse`/`lover`/`kin` 类称谓（妻子、老公、夫君、恋人、男友、父亲…）同时指称两人 → WARN。
- **为何 WARN 不是 ERROR**：纯文本无时点，回忆/倒叙/传闻中提及旧称谓（「我的前妻」「听说是他旧爱」）属正常，需作者确认。故只告警、不阻断。
- **豁免词**（上下文出现则不报）：回忆 / 想起 / 当年 / 曾经 / 听说 / 传闻 / 梦见 / 以为 / 仿佛 / 恍惚 / 旧日 / 往昔 / 故事里。
- **不误报前提**：关系网未登记该 pair，或标签无冲突类别 → 自动跳过。

### 误报控制自查
- 若 C8 报了「回忆段落的旧称谓」，确认正文已写清回忆语境（含豁免词），属预期 WARN，作者核过后忽略。
- 若确为时间线矛盾（如中段已分手、后段却以夫妻相称且无回忆标记），则为真矛盾，应回写正文或 bible。

## 四、情感弧光与伏笔（作者自查，非机判）

- 用 `templates/relationship-map.md` 的「情感弧光追踪表」逐对锁定阶段与卷章。
- 情感伏笔写入 `plot-board.md` 复用 C5（待回收超期告警）。
- 亲密戏尺度完全按用户指令：可留白可露骨，不强制替代写法（见 `10-content-safety.md`）。
