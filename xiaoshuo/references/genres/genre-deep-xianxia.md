# 仙侠 / 玄幻 深度一致性模板

本文件是 `genre-profiles.md` 中「仙侠/玄幻」侧重点的**深度展开**。通用核心（bible + 规划 + 写作 + 校验）见其他 references，这里只规定仙侠**专属的可机判一致性规则**与对应 bible 字段约定。科幻、言情深度模板另行成文件（分批交付）。

> 原则：仙侠最容易出、也最该机器兜底的是「力量体系前后自洽」。以下规则全部**依赖用户按模板规范填写 bible**，校验器不臆造标准——标准是用户定义的境界序列与角色卡。

## 一、必填 bible 字段约定（机器可解析）

要让 C6 等规则生效，world-bible.md 与人物卡必须按以下字段写：

### world-bible.md（新增「力量体系」节）

```
## 力量体系
- 境界序列：炼气 < 筑基 < 金丹 < 元婴 < 化神 < 炼虚 < 合体 < 大乘 < 渡劫
- 境界序列说明：每一大境界分前/中/后/巅峰小阶；序列只列大境界，小阶用于细化不强制。
- 灵力规则 R10：灵力耗尽者在 12 时辰内 禁止 再次运转灵力，否则经脉寸断。
- 资源限制 R11：筑基期及以下 不得 御使本命飞剑（需金丹期方可）。
```

### characters/<角色>.md（新增「当前境界」字段）

```
# 人物：沈砚
- 当前境界：金丹
- 当前状态：在世
- 在场时间线：卷1-卷6
```

## 二、仙侠专属校验规则

| 规则            | 级别    | 检测逻辑                                                 | 已知误报边界（需人工排除）                          |
| ------------- | ----- | ---------------------------------------------------- | -------------------------------------- |
| **C6 境界倒退**   | ERROR | 角色卡「当前境界=X」，正文出现「X 跌落至/跌回/被打落/退至 Y」且 Y 在境界序列中排在 X 之前 | 上下文含「散功/自废/兵解/重修/封印修为/境界被废」属正常情节，已自动豁免 |
| **C4-灵力**     | ERROR | world-bible 灵力规则含「禁止/不得」动作词，正文出现该动作                  | 同 C4 通用边界：需作者确认是否属例外设定（如借外力、特殊功法）      |
| **C4-资源**     | ERROR | 资源/法宝限制规则（如「筑基期不得御剑」），正文低阶角色出现该能力                    | 同上；若有「获得越级外挂/传承」情节需人工确认                |
| **战力不崩（软规则）** | WARN  | 低阶角色在无明确契机下越级胜高阶                                     | 属主观判断，仅提示不报 ERROR；契机需在正文写明             |

## 三、仙侠常见矛盾清单（写作时自查）

1. 境界倒挂：前文金丹，后文突然变回筑基却无散功设定。
2. 能力越级：筑基期角色御使本命飞剑（按 R11 应金丹方可）。
3. 瓶颈跳跃：突破无铺垫（如直接从炼气跳元婴）。
4. 寿元矛盾：凡人角色活过千年未入道。
5. *地图/宗门关系：A 宗与 B 宗前文结盟、后文无交代地敌对。*
6. 法宝归属：某剑前文已毁，后文原样重现且无修复/重铸说明。

## 四、误报控制纪律

- C6 只报「明确倒退动词 + 序列中更靠前境界」，不报「境界提升」「境界持平」「未提境界」。
- 豁免词（散功/自废/兵解/重修/封印修为/境界被废）出现即不报，避免误伤正常情节。
- 若仙侠项目不用境界序列（如「等级制/血脉制」），C6 自动跳过（realm_seq 为空），不误报。

## 五、与其它类型的衔接

- 仙侠常与「言情」混合（仙侠言情）：关系网一致性按 `genre-profiles.md` 言情侧重点，本文不重复。
- 仙侠的「时间线/纪元」多用年号纪年，C2 已支持「Xxx元年/三年」等年号格式。
