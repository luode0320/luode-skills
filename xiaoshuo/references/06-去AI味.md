# 06 去AI味

**这是 7 个源里重复最多的一块——5 个源各写了一遍。** 本文件把它们收敛成一份权威。

> 收敛来源：cn-novel-craft 的可机检量化门禁 + MuMuAINovel `story-deslop` 的 6 Gate 执行步骤 + novel-writing-assistant 的 C11 探测 + human-writing 的成稿硬禁令 + tomato 的 AI 痕迹清单。
> 已拒绝：tomato 的 18.7KB anti-ai-style 原文（与本节重复度过高），只保留其「四大死亡气味」这一独有内容。

---

## 一、先明确一件事：去AI味只改「怎么说」

AI 味不是语法错误，是**风格问题**——过于书面化、过于对仗工整、过于面面俱到。

**三个原则**：

1. **不是改错，是改味**。
2. **改最少，效果最大**：能改一个词就不改一句，能删一句就不重写一段。
3. **保留作者意图**：剧情、人设、情节走向一概不动。原文有逻辑问题，那不是去AI味的活。

---

## 二、真人写作基准（对照表）

| 维度 | 真人写法 | AI 写法 |
|---|---|---|
| 段落长度 | 1–3 句为主，偶尔 1 句独占一行 | 每段 4–6 句，整齐均匀 |
| 对话标签 | 60%+ 无标签，用动作替代 | 几乎每句都有「说道/问道」 |
| 情绪表达 | 动作展示（「手在抖」） | 直接告诉（「很紧张」） |
| 比喻 | 生活化（「像哈士奇护食」） | 文学化（「如寒冰般」） |
| 语气词 | 「嘤」「嘶」「靠」「行吧」 | 几乎没有 |
| 省略 | 大量省略，读者自己脑补 | 面面俱到，生怕读者不懂 |
| 排比 | 偶尔 1–2 个 | 连续 3–5 个是标配 |
| 结尾 | 动作/对话收尾 | 总结/升华/感慨收尾 |

## 三、6 Gate（按需启用）

先判 AI 味程度，再决定过几道：

| 程度 | 特征 | 过哪几道 |
|---|---|---|
| 轻度 | 少量禁用词，偶有书面腔 | A + B |
| 中度 | 多处禁用词 + 句式套路 + 心理抽象 | A + B + C + D |
| 重度 | 节奏/对话/结尾都有问题 | 全部 6 Gate + 重点段重写 |

### Gate A：禁用词替换

**零容忍词**（出现即改）：

`不禁 / 与此同时 / 一股XX涌上心头 / 内心深处 / 缓缓说道 / 命运的齿轮 / 宿命感 / 忍不住 / 下意识地 / 不由自主地 / 眼中闪过一丝 / 嘴角勾起一抹`

**warn 词**（每章 ≤3 次）：

`深吸一口气 / 时间来到了 / 另一边 / 仿佛 / 似乎 / 他知道 / 她知道`

**替换规则**：禁用词 → 具体动作/细节，**不能简单换成另一个形容词**。

| 原句 | 改后 |
|---|---|
| 眼中闪过一丝不易察觉的悲伤 | 他垂下眼 |
| 深吸一口气 | 胸口起伏了一下（或直接删，这个动作 90% 无意义） |
| 嘴角勾起一抹冷笑 | 他笑了一下，没到眼底 |

### Gate B：句式去套路

| 句式 | 问题 | 替代 |
|---|---|---|
| 「…，带着…」 | 万能状语 | 独立短句或动作 |
| 「像XX一样」 | 陈词比喻 | 换比喻或白描 |
| 「他/她知道…」 | 直接告诉 | 用行为展示 |
| 「XX说道」 | 机械标签 | 用动作替代 |
| 「仿佛/犹如/宛若」 | 文言腔过重 | 口语化或白描 |
| 「不容置疑/显而易见」 | 书面判断词 | 用具体事实说话 |

### Gate C：心理描写外化

见 `04-正文技法.md` 的情绪外化表。

### Gate D：节奏打碎

- 打断连续排比（保留 1–2 个，删其余）
- 长句拆短句
- 偶尔用不完整句
- 段落长短交错

### Gate E：对话去腔调

- 加口语化表达（「嗯」「哦」「行吧」）
- 允许答非所问
- 用动作穿插对话
- **删掉解释性对话**（角色不会把自己的动机讲清楚）

### Gate F：结尾去升华

- 删总结性语句
- 用动作/场景收尾
- 「他知道…」「这一刻…」→ 基本可以删

## 四、四大死亡气味（出现即高危）

1. 堆砌排比
2. 三段式强行升华
3. 空洞象征
4. AI 套话（「众所周知」「不言而喻」「值得注意的是」「需要指出的是」）

## 五、可机检的量化门禁（10 项）

每章生成后跑一遍，**能机检的不靠感觉**：

| # | 检查项 | 阈值 |
|---|---|---|
| 1 | 字数 | 常规章 ≥3000 字 |
| 2 | 破折号 | ≤12 处/章（第五节口径见下方说明） |
| 3 | 禁用词 | 零容忍 |
| 4 | warn 词 | ≤3 次/章 |
| 5 | limit 词 | 每种不超限 |
| 6 | 钩子 | 必须存在，类型 ≥1 种 |
| 7 | 对话标签 | 裸标签 ≤30% |
| 8 | 章末 | 非反问 / 非感叹 / 非平收 |
| 9 | 情绪命名（「感到/觉得」） | ≤2 次/章 |
| 10 | 段落均匀度 | 长短句交替 |

> **第五节与第六节的口径关系**：本节是**体检扣分线**（超过就扣分，扣完仍可能及格），第六节是**成稿硬禁令**（命中即不能交稿）。两节都提到破折号但强度不同，冲突出现时**以第六节为准**——本节只用于早期草稿的量化体检，进入交付前必须按第六节清零。

```bash
python scripts/tomato_audit.py <稿件文件或目录> --json
```

## 六、成稿硬禁令（活人感侧，小说通用）

以下覆盖标题、正文与引用转述，**命中一项就不能交稿**：

- 不用中文冒号「：」和英文冒号「:」。（正文叙述层；对话内、代码、机器字段除外）
- 不用破折号「—」和「——」。
- 不用「不是…而是…」「并非…而是…」「不在于…而在于…」「与其说…不如说…」「表面…实际…」「看似…实则…」及其变形。
- 不用「说白了」「说穿了」「先说结论」。
- 不把「更微妙的是」「还有一层」「值得注意的是」「从某种意义上说」当洞察路标。

```bash
python scripts/check_prose.py <稿件路径>
```

脚本失败就继续改，直到禁用项清零。

## 七、二遍改写工作流（固定四步）

1. **跑探测**：`consistency_audit.py` 的 C11 扫首版信号。
2. **照单改**：按本文件 Gate A–F 逐条处理被点名的位置。
3. **重跑确认**：C11 清零。
4. **定稿**。

**逻辑问题（C1–C10）始终优先修**，文风问题是第二位。

---

## 八、去AI味的边界

探测器能抓的是「机械信号」（高确定性、低误报）。但「文风是否灵动、是否有个人腔调」属于审美，**脚本判不了**——那一步必须靠人（或按本文件重写）。

**不要声称脚本能判定文风好坏。** 它只能列出雷点清单。
