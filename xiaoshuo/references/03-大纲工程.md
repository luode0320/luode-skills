# 03 大纲工程

大纲不是故事梗概，是**可以照着写、可以逐章对账、改一处知道牵动哪几章**的结构。

> 来源：novel-outline v1.0.0 的六层模型与七步判据（主力），叠加 tomato-palace-master 的分卷架构与钩子密度要求。

---

## 一、大纲的分层（六层）

结构自上而下，**上一层定死，下一层才展开**：

| 层 | 回答什么 | 产物 | 粒度 |
|---|---|---|---|
| L1 卖点 | 读者凭什么追下去 | 一句话卖点 + 读者承诺类型 | 1 句 |
| L2 世界观 | 世界有什么规则、边界在哪 | 规则卡（规则+边界+代价） | 数条 |
| L3 主线 | 主角要什么、被什么挡、怎么升级 | 主线句 + 升级路径 | 1 条线 |
| L4 人物 | 谁在场上、各自要什么、弧光 | 人物卡 | 每人 1 卡 |
| L5 分卷 | 整本书切成几卷、每卷干什么 | 卷脉络表 | 一卷一行 |
| L6 章纲 | 每章发生什么、停在哪 | 章细纲表 | 一章一行 |

七步流程对应六层：L1 一步，L6 拆成「拆章纲」「埋钩子」两步。

---

## 二、七步作业

### 第 1 步 · 定卖点

**模板**：

```
一个【什么人】，因为【什么事】，必须【做到什么】，否则【失去什么】。
```

三格都填得出才算过。**读者承诺类型**选一：变强复仇 / 看一个人如何自处 / 学会一套生存规则 / 解谜 / 情感圆满 / 群像共鸣。

典型病：卖点＝设定（「穿越到修仙界」是设定不是卖点）；卖点＝情绪词（「爽」「热血」）；卖点里没有「否则」——没有代价的承诺，读者不怕。

### 第 2 步 · 立世界观

规则卡三列：

| 规则 | 边界（什么情况下不成立） | 代价（用了要付什么） |
|---|---|---|
| 灵气可修，靠功法等级 | 无灵根者不能修 | 修到瓶颈需渡劫，失败身死 |

**纪律**：只立「主线用得到」的规则，不写百科全书。立了不用＝废规则。

### 第 3 步 · 定主线

```
主角要【目标】，但【阻碍方】挡着，他靠【升级方式】一步步接近。
```

阻碍必须是**活人 / 活组织**，不是环境。升级路径四选一：换更大的对手 / 换更近的背叛 / 换更高的规则 / 换更深的自己。

**主线只有一条**。支线必须写清「在哪一章汇入主线」，写不清的支线＝赘线。

### 第 4 步 · 立人物

| 字段 | 内容 |
|---|---|
| 想要什么 | 一句话，与主线同源或直接冲突 |
| 怎么挡/帮主角 | 具体到动作，不是「很坏」/「很好」 |
| 弧光三节点 | 起点 → 转折（触发事件）→ 终点 |
| 专属钩子 | 一条只有他会做的事 |

**纪律**：主角只有一个（群像＝轮流高光，不是轮流当主角）；对手要有**具体可恨的事**，落到物件/数字/可见后果上。

### 第 5 步 · 排分卷

| 卷 | 从哪到哪 | 本卷对手 | 要解决 | 卷末翻什么 | 主角变什么 |
|---|---|---|---|---|---|
| 1 | 下山 → 入宗门 | 外门管事 | 站稳脚跟 | 身份 | 从废柴到被认可 |

**纪律**：卷末必翻一样（地位/关系/认知/信息四选一）；卷与卷靠「换更大的对手」或「换更深的自己」衔接，不靠「又来了一个新事件」。

### 第 6 步 · 拆章纲

| 章 | 发生什么 | 谁出场 | 推进哪条线 | 章末停在哪 | 埋/收 |
|---|---|---|---|---|---|
| 1 | 主角发现灵根被夺 | 主角、对手 | 主线启动 | 决定查真相 | 埋「谁夺的」 |

**纪律**：一次只展开一卷；章纲仍不是正文——不写场景、不写对白、不写字数；每章只有一个核心动作。

### 第 7 步 · 埋钩子

**判据**：章末最后一段，读者能复述成一个**关于主角的**问句——他会不会…／他要不要…／他能不能…

**不算钩子**：环境信号（火把、天亮、风声、远处响枪）——读者复述不出关于主角的问题。

**钩子＝问题 + 选择**。每章一个钩子，不许堆两个。

## 三、节奏密度（网文向）

| 层级 | 密度 |
|---|---|
| 小爽点 | 每 3000 字一次（约每章） |
| 中爽点 | 每 10000 字一次（约每 3 章） |
| 大爽点 | 每 30000–50000 字一次（约每卷） |
| 章末钩子 | 每章必有 |

**连续三章无爆点 = 重写。**

## 四、钩子类型轮换

八种类型：危机 / 悬疑 / 反转 / 信息 / 情感 / 时间 / 选择 / 生存。

- 连续 3 章不可用同一种。
- 每 5 章内覆盖 ≥ 4 种。
- 禁反问结尾、禁感叹结尾、禁平收。

## 五、叙事结构参考

三套通用框架（**属常识性写作理论，非平台标准**）：

- **三幕剧**：建置 25% / 对抗 50% / 结局 25%。强情节商业长篇适用。
- **Save the Cat 15 节拍**：催化剂 10% → 中点 50%（假胜利/假失败必含）→ 一切失去 75% → 暗夜灵魂 75–80% → 终极对决 80–99% → 终场 99–100%。
- **Story Circle（章级）**：YOU → NEED → GO → SEARCH → FIND → PAY → RETURN → CHANGE。

**网文节奏公式**与 MRU 单元（刺激→反应）见 `references/04-正文技法.md`。
