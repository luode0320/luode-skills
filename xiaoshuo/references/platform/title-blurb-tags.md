# 书名 · 简介 · 标签公式库（流量门面工程）

> 知识截止：2026-09-11。依据：2026-08-31 第 34 期雷达命名公式拆解、8-18 第 3 期书名结构统计、番茄读者结构（45 岁以上活跃用户 1.21 亿，占比 45.7%，下沉/中年/情绪直给）。
> 用途：书名与简介是**唯一决定点击率**的东西。正文再好，门面拉胯就没人进来。

---

## 一、书名工程

### 1.1 趋势硬数据

| 指标 | 数据 | 含义 |
|---|---|---|
| 超 15 字标题占比 | 28% → 36% → 42%（三期连涨） | 书名持续加长 |
| 平均书名字数 | 11.2 → 12.8 字 | 长标题成为主流 |
| 标点使用率 | 同比 **+40%** | 感叹号、逗号、省略号、冒号显著提升点击率 |
| "我"字开头占比 | 34% | 第一人称代入感成主流 |

**新人建议区间：12–20 字**。除非已是头部作者，**避免纯古风简洁型**（《烟雨楼》《凡骨》这类是成熟作者的护城河）。

### 1.2 六种公式（2026 现行，按有效性排序）

| # | 公式 | 模板 | 示例 |
|---|---|---|---|
| 1 | **身份反差型** | 身份 + 冲突动作 | 《大一实习，你跑去 749 收容怪物》《穿成女频男主，我天天报警》 |
| 2 | **悬念钩子型** | 反常现象 + 疑问/感叹 | 《时停时停…时停!》《谁把我仙侠游戏退出键扣了?》 |
| 3 | **场景颠覆型** | 熟悉场景 + 陌生规则 | 《我在精神病院学斩神》《系统想害我，我选择上交国家》 |
| 4 | **能力声明型** | 我能/我是/我有 + 特殊能力 | 《我能看到所有奇遇》《我不是戏神》 |
| 5 | **历史嫁接型** | 时代/人物 + 现代梗/反差 | 《大唐：活着就变强？可我永生啊!》 |
| 6 | **情绪极端型** | 极端情绪词 + 身份/动作 | 《癫，都癫，癫点好啊》 |

### 1.3 书名生成公式（五步产 12 个候选）

```text
Step 1  写下核心设定（5-8 字）：例"穿成女频男主"
Step 2  写下反常行为（8-12 字）：例"我天天报警"
Step 3  拼接并加标点：逗号/感叹号/省略号/冒号任选一 → 《穿成女频男主，我天天报警》
Step 4  套六种公式各生成 2 个变体 → 12 个候选
Step 5  按下方"点击率四问"筛出 3 个终选，标注推荐理由
```

### 1.4 点击率四问（终选筛子）

1. 读者能不能在 **2 秒内**说出"主角是谁 + 有什么特殊 + 会爽在哪"？
2. 有没有一个**具体的反常信息**（不是泛泛的"逆袭""无敌"）？
3. 有没有情绪或标点钩子（疑问、感叹、省略号）？
4. 会不会和已上榜的书撞车到读者分不清？（同名/近名必须换）

### 1.5 命名禁忌

- 纯意境无信息（读者不知道能得到什么爽感）；
- 超 22 字（手机列表显示不全）；
- 生僻字、需要解释的专有名词；
- 与当期榜单头部作品高度相似（会被算法与读者双重淹没）；
- 标题党但与正文不符（完读率会崩，得不偿失）。

## 二、简介工程

### 2.1 简介的算法作用

简介参与**内容标签抓取**——系统会从简介里提取题材、设定、情绪关键词，用于匹配兴趣人群。因此简介不是广告词，是**标签源**。

### 2.2 四段式简介结构（推荐）

```text
【第 1 段 · 处境冲突】（1-2 句）主角现在的绝境，带具体事实。
【第 2 段 · 转折钩子】（1-2 句）金手指/反常能力/身份反差首次出现，说明代价或限制。
【第 3 段 · 爽点预告】（1-2 句）主角将要做什么，读者能得到什么爽感，用具体场面而非形容词。
【第 4 段 · 悬念收尾】（1 句）留一个未解问题，或者一句高情绪张力的短句。
```

**篇幅**：120–260 字为宜。手机端前 3 行是黄金位（约 60 字），核心钩子必须放在这里。

### 2.3 简介写法对照

| 项 | ❌ 低质写法 | ✅ 殿堂写法 |
|---|---|---|
| 冲突 | "他的生活发生了翻天覆地的变化" | "他被判死刑那天，法医报告上写着——此人已死六年" |
| 能力 | "他拥有强大的系统" | "系统只说三句话，每句要他一条命" |
| 爽点 | "他将一路无敌" | "他把县衙的账本倒背如流，第二天知府的师爷跪着来求他" |
| 情绪 | "充满了热血与激情" | "他抬眼看了看满朝文武，笑了一声，把刀放在了龙案上" |

**铁律**：**具体 > 抽象，场面 > 形容词，动作 > 状态。** 凡是能用画面写出来的，绝不用形容词概括。

### 2.4 简介自检五问

1. 前 60 字里有没有出现核心设定与冲突？
2. 有没有任何一个抽象形容词（"强大""无敌""逆天"）可以换成具体场面？
3. 有没有说明金手指的代价或限制？
4. 读完之后读者知不知道"这本书爽在哪"？
5. 有没有承诺与正文不符的内容？

## 三、标签工程

### 3.1 标签的作用机制

平台标签体系决定初始推荐人群。**标签错 = 推错人 = 点击率天然低**。写对标签，比多写一万字更影响早期数据。

### 3.2 2026-08 全平台标签热度前 40（择优选标签，优先高热度且贴书的）

### 3.3 标签搭配策略

| 目标 | 推荐组合 | 理由 |
|---|---|---|
| 男频脑洞 | 穿越/系统 + 都市 + 爽文 + 无女主/单女主 | 标签热度最高，人群最大 |
| 悬疑向 | 悬疑 + 灵异 + 无限流 + 群像 | 上升赛道，黏性强 |
| 历史蓝海 | 历史 + 穿越 + 架空 + 爽文 | 供给稀缺，竞争小 |
| 女频情绪 | 现代言情 + 甜宠 + 重生/穿越 + 先婚后爱 | 女频基本盘 + 趋势元素 |
| 女频悬疑 | 悬疑 + 灵异 + 无限流 + 现代言情 | 女频新增长极，蓝海 |
| 克系向 | 穿越 + 悬疑 + 都市高武 + 克苏鲁 | 从亚文化走向主流，稀缺度高 |

**搭配三原则**：
1. **贴书优先**于热度——错标签带来的错误人群会直接压低完读率；
2. **一个大热度 + 两个精准 + 一个趋势**为佳，不超过 5 个；
3. 反系统/无系统是 2026 新趋势（占榜单 36%），若作品符合，优先打"无系统"标签做差异化。
