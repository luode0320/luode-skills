## 受影响运行路径

1. `write` / `upsert_projection`：读取注册表，按 `session_id` 合并目标投影，锁内原子写回。
2. `validate` / `payload`：按 `session_id` 精确读取，拒绝跨会话恢复。
3. `deactivate` / `goal`：只改变当前会话投影，保留其它会话状态。
4. `migrate`：把 v1-v3 单投影绑定真实 `session_id` 并升级为 v4 registry。
