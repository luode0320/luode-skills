## 3.1 本轮改动引入并已修复的回归

| 编号 | 现象 | 根因 | 修复 |
| --- | --- | --- | --- |
| REG-01 | ListPage 卡片报 `Cannot read properties of undefined (reading 'map')` | 受控回写把样本状态做成 `reactive`，深响应将 `list.rows/total/page` 等嵌套 ref 自动拆包，而 `ListPage` 契约就是接收 composable 返回值并按 `list.rows.value` 读取，拆包后 `.value` 为 undefined | `use-live-props.ts` 改用 `shallowReactive`，只跟踪顶层键赋值，保留样本内 ref 原样透传 |
| REG-02 | BoardView 卡片报 `Cannot read properties of undefined (reading 'length')` | 浅响应修好后 `boardDemo` 的 `ref(columns)` 不再被拆包，组件拿到的是 ref 对象而非数组 | `boardDemo` 改用 `reactive` 数组，不再依赖外层拆包，看板样本自洽 |

REG-01/REG-02 都是「先改坏、真实浏览器跑出来、再修」的产物，最终 0 失败卡片由 RUN-01 复验。

## 4. 只读组件的豁免说明（不是缺陷）

逐个判据复核后，40 个无操作句柄的组件语义上本就是只读展示件：Icon/Avatar/Tag/StatusTag/Badge/DeltaPill/Metric/Odometer/SpecPlate/KeyValueReadout/ReadoutStrip/SectionLabel/Divider/GridRow/GridCol/Space/BentoGrid/BentoCard/Card/CardGrid/CardMeta/ShareList/ActivityList/Timeline/TimelineItem/Countdown/Progress/Spin/Result/EmptyState/Skeleton/Watermark/Ruler/NeuralNet/BarChart/TrendChart/TickRing/DictTag/Descriptions/TabPane/Affix/StyledScrollbar 等。它们不产生状态，不给操作句柄是正确设计，不为其补交互。

## 5. 取证陷阱与经验

- **`innerHTML` 比较会误报**：Vue 重渲染是异步的，同一 tick 内比较必然显示"未变化"；必须 `点击 → setTimeout → 比对`。
- **卡片内查找会漏判浮层**：Dropdown/Image 预览/Tooltip 通过 `Teleport to="body"` 渲染，`.sc-cell-body` 内查不到，必须查 `document`。
- **异步组件首帧为空**：`defineAsyncComponent` 挂载初期 `textContent` 为空，过早统计会把有内容的组件（Button/Tag/Avatar 等）误报为空白卡片；应等待完成加载后再用 `innerText` 统计。
- **toggle 组件跨轮次状态残留**：连续多轮探测时，上一轮已把组件打开/推进（如 Steps 的 `current` 被写成 0、Dropdown 已开），下一轮同元素点击表现为"无变化"。判交互必须以状态迁移而非单次点击结果定论。

## 6. 未覆盖项与已知缺口

- 键盘导航（Tree/Anchor 的上下键、Esc 关浮层）未逐项自动化验证，属人工可补测项；本轮以指针事件与受控回写为主证据。
- 看板 `BoardView` 的真实拖拽落列依赖指针轨迹（pointerdown→move→up），本轮以「移动到…」按钮入口验证了数据搬运真实生效（`[2,1,1] → [1,2,1]`），未做完整拖拽轨迹仿真。
- **列排序缺失（记录不实现）**：按「Textarea 式」复核每个 merged 声明时发现，`ui/DataTable.vue` 全仓无 `sortable`/`sortKey` 实现，即 Arco Table 的列排序能力确实缺失。本项不在本轮补：该组件属上游冻结层（改它会破坏 `FIDELITY` 字节基线），且被 9 个页面消费，在 extend 层再造一套表格会违反同语义防重复封装。留待以正常需求立项评估。
- 其余已复核的 merged 声明经代码确认为真：Select 分组由 `options[].depth` 实现（`Select.vue:182` 有缩进渲染）、Skeleton 行/形状由 `rows` + `type` + `animation` 驱动（`Skeleton.vue:8-17`）。
