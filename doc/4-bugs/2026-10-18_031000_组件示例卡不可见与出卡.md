# 组件示例卡不可见与出卡 Bug 主文档

结论：示例页存在两类「组件在卡内看不见」的问题，一类是 `BackTop` 的四个示例把按钮渲染到视口右下角、完全落在示例卡之外，另一类是 `TabPane` 的「未激活」示例因 `v-show` 隐藏整块而呈现空白卡，另有一条纵向分割线因缺少并排邻居而塌成 1em 短线；影响：`/gallery/navigation/locate` 与 `/gallery/navigation/tabs`、`/gallery/layout/divider` 三个页面的示例无法用于核对；范围：`BackTop` 的停靠定位能力、示例变体装配层的外框能力、三条示例变体；非范围：`TabPane` 的显隐语义、`Divider` 的线型实现、上游冻结模板；变化：`BackTop` 新增 `container` 属性并让按钮在示例卡内停靠，示例层新增并排外框，移除无可见差异的空白示例；完成标准：全量 752 张示例卡扫描零异常、`BackTop` 四个示例全部落在卡内、纵向分割线在卡内有可见高度、其余守卫全绿；术语说明：出卡指组件根元素完全落在示例卡内容区可视矩形之外，塌缩指元素可见但宽或高小于 4 像素；验证状态：已用运行时几何、全量扫描、多视口复验与截图确认。

## 1. 结论

用户截图里四个空白卡不是渲染失败，而是 `BackTop` 的按钮按视口固定定位，飘到了浏览器右下角，完全落在示例卡内容区之外。

全量体检 101 个页面、752 张示例卡后，共发现 6 处异常，分成三类：

| 类别 | 数量 | 组件 | 性质 |
| --- | --- | --- | --- |
| 出卡 | 4 | `BackTop` 的四个示例 | 组件定位方式与示例容器不匹配，属真实可用性缺陷 |
| 空白卡 | 1 | `TabPane` 的「未激活」示例 | 示例选错了表达方式，组件显隐语义本身正确 |
| 塌缩 | 1 | `Divider` 的纵向派生示例 | 示例缺少并排邻居，组件线型本身正确 |

三类都修在示例呈现与组件停靠能力上，没有改动 `TabPane` 与 `Divider` 的组件语义。

## 2. 症状

- `/gallery/navigation/locate` 的四个 `BackTop` 卡片内容区完全空白，页面上看不到按钮；实际按钮被渲染到视口右下角，与卡片位置无关。
- `/gallery/navigation/tabs` 的 `TabPane`「未激活」卡片内容区空白。
- `/gallery/layout/divider` 的 `direction=vertical` 卡片里只有一条高 13 像素的竖线，看不出分割语义。
- 其余 746 张卡片的内容都在各自内容区内可见，未命中体检判据。

## 3. 复现步骤

1. 启动组件库：双击 `frontend-design/component-library/启动组件库.bat`，或执行 `npm run dev`。
2. 用任意账号密码登录（本地 mock 放行）。
3. 打开 `/gallery/navigation/locate`，观察 `BackTop` 四张卡：内容区空白。
4. 打开 `/gallery/navigation/tabs`，观察 `TabPane`「未激活」卡：内容区空白。
5. 打开 `/gallery/layout/divider`，观察 `direction=vertical` 卡：只有一条短线。

稳定性：稳定复现，与数据无关；`BackTop` 四张卡必现，另外两类为单卡必现。

## 4. 诊断证据

| 证据 | 来源 | 结论 |
| --- | --- | --- |
| 全量体检输出 `pages 101 cells 750 findings 6`，其中 4 条 `BackTop all-outside`、1 条 `Divider all-tiny`、1 条 `TabPane all-hidden` | 临时体检探针扫描全部 101 个三级路由 | 异常范围与数量确定 |
| 修复前 `BackTop` 按钮矩形为视口右下角，与内容区矩形完全不相交 | 同一探针读取 `getBoundingClientRect` | 按钮按视口固定定位 |
| `BackTop` 根元素是 `position: fixed` 的按钮，没有定位祖先可停靠 | `src/components/extend/BackTop.vue` 原样式块 | 组件没有容器内停靠能力 |
| 纵向分割线实测 `w=1 h=13`，计算样式 `min-height: 13px` | 浏览器运行时探针 | 高度来自 `min-height: 1em`，无邻居撑开 |
| `TabPane` 未激活卡内所有元素 `display: none` | 同一探针 | `v-show` 隐藏整块 |
| `Divider.vue` 纵向分支为 `width: 0` 加 `border-left: 1px`，`align-self: stretch` | `src/components/extend/Divider.vue` 第 77 至 84 行 | 竖线高度由父级行高决定，属正确实现 |

## 5. 根因

三类问题根因不同：

1. **`BackTop` 出卡**：组件把按钮写成 `position: fixed`，参照系是视口。示例卡是一个有滚动容器的普通区块，按钮不会跟随卡片，于是飘到视口右下角。组件缺少「在指定容器内停靠」的能力，调用方也无法通过属性改变定位参照。
2. **`TabPane` 空白**：`active: false` 时组件按设计用 `v-show` 隐藏整块。把「未激活」单独做成一格示例，等于主动渲染一块空白，示例本身无法呈现组件形态。
3. **`Divider` 塌缩**：纵向分割线靠 `align-self: stretch` 撑满父级行高，单独挂载时父级只有一行字高，竖线只剩 `min-height: 1em`。组件实现正确，缺的是并排上下文。

## 6. 修复

| 项 | 内容 |
| --- | --- |
| `BackTop` 停靠能力 | 新增 `container` 属性；组件根改为 `div.x-backtop-anchor`，用 `position: absolute; inset: 0` 铺满直接父元素，按钮在有停靠宿主时改绝对定位，否则维持视口固定 |
| `BackTop` 定位上下文 | `bind()` 给停靠宿主补 `relative`，保证锚点有真实尺寸；`hostReady` 在挂载后驱动 `anchorStyle` 重算，避免首帧退化成视口固定 |
| `BackTop` 示例取值 | 三组示例改为 `right: 16` / `right: 16, bottom: 32` / `right: 120, bottom: 16`，保证 42 像素按钮落在 74 像素高的内容区内 |
| 示例外框能力 | 变体类型新增 `frame`（左右上下文文字与行高），装配层透传，示例页按并排布局渲染 |
| 纵向分割线示例 | 生成器剔除无上下文的 `direction=vertical` 派生项，改由策展条目给出三组带并排外框的示例 |
| `TabPane` 示例 | 移除「未激活」空白示例，改为三组可见的内容差异示例；未激活语义由 `Tabs` 示例通过切换标签演示 |
| 是否触及冻结面 | 否，`extend/` 与 `views/gallery/` 均为本地扩展层 |
| 回滚 | 移除 `container` 属性与锚点根节点即回到原视口固定行为；示例变体为纯数据，删除条目即可 |

## 7. 全量排查

用户要求「检查所有组件」，因此新增体检守卫 `frontend-design/scripts/check_demo_visibility.py`，对 101 个三级路由的全部示例卡按三条判据扫描：

- **空白卡**：内容区可见元素数为 0。
- **出卡**：组件根元素完全落在内容区可视矩形之外。
- **塌缩**：内容区有元素，但可见宽与高都小于 4 像素；1px 竖线是线状组件的形态，不判塌缩。

路由清单从分类数据源派生，不手抄，避免漏页。守卫内置三项自证：阳性对照（注入视口固定元素必须被出卡判据命中）、示例卡数量下限、空页检测——三者任一不成立即判守卫失效，防止扫描根不全时的 0 命中被误读成通过。

扫描结果 750 张卡命中 6 处，全部完成归类与修复；修复后 752 张卡零命中。

## 9. 未覆盖说明

- 体检探针只判「完全不可见」与「完全出卡」，不判「部分遮挡」；部分遮挡需要逐卡视觉判断，不在本轮自动化范围。
- 纵向分割线的外框行高固定为 72 像素，只用于示例呈现，不改变组件默认的 `1em` 行为。
- `BackTop` 的 `container` 属性需要调用方传入元素；不传时保持原有视口固定行为，未做破坏性变更。
- 体检探针为临时排查工具，收口前已删除，不进入长期守卫。

| 标准 | 判定方式 | 实际结果 |

## 11. 排查过程中修正的判据与设计错误

| 错误 | 表现 | 修正 |
| --- | --- | --- |
| 试图在示例页注入容器引用 | 装配层读非响应式 Map，首帧拿不到元素，方案失败 | 改为组件自查找直接父元素，示例页无需配合 |
| 锚点用 `display: contents` | 不生成盒，不能作为定位祖先 | 改为 `position: absolute; inset: 0` |
| 锚点用 `position: relative` 但零尺寸 | `right/bottom` 相对 0 点计算，按钮被推到锚点左上方 | 锚点铺满父元素，父元素补 `relative` |
| `anchorStyle` 用普通函数 | `hostReady` 变化不触发重算，首帧退化成视口固定 | 改为 `computed` |
| 示例卡容器注入方案 | 需要改示例页渲染管线，首帧时序脆弱 | 完整回退，改用组件自洽方案 |
| `Divider` 纵向派生项保留在生成器 | 无上下文的派生项会继续产出塌缩卡 | 加入不可见候选黑名单，由策展条目接管 |
| `TabPane` 保留未激活示例 | 空白卡无法核对组件形态 | 移除该变体，改由 `Tabs` 演示未激活语义 |
