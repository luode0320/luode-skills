## Agent 对当前问题的理解

当前 Markdown 文档生产能力分布在多个领域 skill 中，缺少独立的公共呈现 Owner。PPTX skill 中已经存在可复用的内容组织和视觉验收原则，但它们不能直接复制到 Markdown。实施目标是建立一个只负责 Markdown 呈现的公共 skill，并让领域 skill 只通过引用复用。

当前优先闭环：

1. 持久化需求和实施计划；
2. 创建公共 skill；
3. 接入第一批消费者；
4. 运行 skill、文档、Mermaid、字典和合规门禁；
5. 形成可回滚、可交接的证据链。

## 任务完成、停止与最大推进边界

### 完成定义

- 八个任务按顺序完成；
- 每个任务先实现、再真实测试、再 6-review；
- 所有计划文档通过 profile；
- 所有 skill 通过 quick validation；
- 字典、Mermaid、合规和审计通过；
- 既有脏工作树没有被清理。

### 停止定义

- 任一关键 profile 失败；
- 任一 Mermaid parser 失败；
- 任一职责边界无法统一；
- 任一超范围文件被改动；
- 任一未授权外部项目访问出现。

### 最大推进边界

本轮只实现公共 Markdown skill 和首批消费者，不修改历史 Markdown、不修改 PPTX 业务职责、不安装外部依赖、不提交 Git。
