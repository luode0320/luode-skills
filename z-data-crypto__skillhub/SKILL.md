# 加密货币行情速查官

> 类型：常规 Skill（行情速查官）｜slug：`z-data-crypto`｜版本 V1.0.0

## 一、定位 / 适用边界
- **定位**：加密货币行情速查官：输入币种即返回最新价格、24h 涨跌与市值要点。
- **适用**：当用户要查 BTC/ETH 等加密货币行情时使用。
- **不适用**：与本类其他 Skill 边界不同（见下方红蓝对抗），不替代专业服务/官方系统。
- **标签**：加密货币, 行情, 数据, 区块链

## 二、触发词
加密货币 / 币价查询 / crypto / 查币

## 三、章节地图
标 / 的 / 识 / 别

## 四、工作流程
识别标的（代码/名称/行业）→ 拉取最新行情或数据 → 给出对比与走势要点 → 标注数据来源与时效 → 声明非投资建议。数据来自公开接口，实时性以源为准。

## 五、输出规范
输出=关键数值卡片(最新价/涨跌/估值等)+简短对比+来源链接+‘仅供参考’声明。

## 六、红蓝对抗（高频疑问）
Q：数据滞后？→说明以数据源刷新为准。Q：查不到？→确认标的代码/名称。Q：能投资建议吗？→仅给数据，不给买卖建议。

## 七、使用建议 / 错题本
建议用户结合多源交叉验证；重大决策咨询持牌顾问。

## 八、红线 / 安全审查
- 行情/数据来自公开接口，仅供学习参考，不构成投资建议；实时性以数据源为准，不承诺准确与时效。
- 不含密钥/token；不生成违规或侵权内容；发布须符合平台规范。
