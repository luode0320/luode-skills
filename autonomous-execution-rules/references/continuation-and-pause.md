# 继续、暂停与高风险边界

本文件承载连续推进节奏和关键节点；不得扩展 `SKILL.md` 的自动触发范围。

### 允许自动继续

- 当前仅完成阶段性子步骤，整体目标尚未闭环。
- 下一步属于原执行计划内未完成的必需项，且仍是完成原始用户目标所必需。
- 下一步可在当前上下文、授权和安全边界内执行。
- 中间进度后仍可继续实现、真实测试、必要修正、`6-review` 或收口。

### 最小任务与周期节奏

- 默认节奏是“当前周期 -> 当前最小任务实施计划完成条件 -> 当前最小任务实现 -> 当前最小任务真实测试 -> 当前最小任务 `6-review` -> 下一个最小任务 -> 当前周期收口 -> 下一周期”。
- 当前最小任务未闭环不得进入下一个任务；当前周期未收口不得跳到下一周期。
- 禁止先完成多个任务的实现，再统一真实测试或统一 `6-review`。
- 当前最小任务进入 `in_progress`、完成为 `completed` 或下一个任务保持 `pending` 时，先落盘任务计划文档状态字段，再更新宿主任务列表（宿主提供任务工具时）。
- Desktop 或宿主中断后恢复到 `in_progress` 步骤时，先核验磁盘、测试和外部状态；未知或非幂等写操作不得自动重放。任务进度重建不改变 `confirmed/unknown/revoked` 执行许可。
- 默认执行回合取得 `confirmed` 后，进度展示走宿主任务工具；宿主没有任务工具时只用任务计划文档状态字段，不阻断执行。
- 可自行消解的不确定项采用最小可逆决策继续；不能自行消解且会改变目标、接口或风险时暂停。

### 必须暂停

- 首次进入编码且执行许可不是 `confirmed`。
- 普通模式开工指令缺少有效计划，或采纳的建议尚未转为计划。用户显式开启或确认且仍 active 的 Goal 不因计划文档缺项命中此暂停项；先按 Goal Owner 修复并落盘计划文档，再继续。
- 上下文压缩后编码许可为 `unknown` / `revoked`。
- 需要新增超出已确认范围的模块、依赖、数据结构或业务逻辑。
- 删除或覆盖大量文件、破坏性数据操作、生产动作、密钥或权限变更等高风险或不可逆操作。
- 外部付费、跨系统联动或预计成本显著增加。
- 信息冲突无法靠现有证据收敛，继续执行有较高做错概率。
- 任务准备进入 Git 动作但当前轮无 Git 授权；若用户当前轮已明确 Git 动作，直接交给 `git-collaboration-rules`。
- 命中用户结束、无合法后续或真实阻断条件。
- Goal 模式下本节暂停项整体收缩；收缩范围与剩余红线一律按 `../../goal-loop-rules/SKILL.md` 的《Goal 模式免确认推进》，本文件不另立判据。

### Goal 模式免确认推进（引用唯一权威）

用户显式开启或确认的 Goal 处于 `active` 时，免确认推进的完整判据——计划视为已完成、分歧自行裁决、推荐方向判定顺序、证据不足走最安全兜底、计划文档缺项自动修复、低风险授权默认通过的五项条件、仍不得突破的红线、防自我授权与退出条件——**唯一见 [`goal-loop-rules/SKILL.md`](../../goal-loop-rules/SKILL.md) 的《Goal 模式免确认推进》一节**。

本文件只保留自主执行侧的两条操作口径，均不得扩大上述授权：

- 连续执行时不停在「如果你要，我可以继续」这类可选话术，应直接推进原计划内的下一项必需动作。
- 只有进入提交授权、强制审批、高风险或越界节点时，才按下方《关键节点提问》暂停。

### 关键节点提问

只说明当前阶段结果、节点类型和 2-3 个互斥选项；推荐项置首。不得用开放式“你想让我接下来做什么”替代可执行决策。

固定格式：

```text
我已完成 <当前阶段结果>。当前进入关键节点：<节点类型>。
建议选项：
1) <推荐选项>（推荐）
2) <备选选项>
3) <保守选项>
```

连续执行示例：当阶段性证据分析完成且下一步仍属于原计划必需项时，不停在“如果你要，我可以继续”的可选话术；应直接推进到下一项必需动作。只有进入提交授权、强制审批、高风险或越界节点时，才使用上述格式暂停；Goal 范围内的免确认推进按 `../../goal-loop-rules/SKILL.md` 的《Goal 模式免确认推进》执行。

### 安全与审批

自主执行不能绕过系统安全限制、权限审批、local 环境边界、外部副作用确认或高风险防护。任何更高优先级安全规则要求暂停时，本 Skill 必须停止继续。
